# 003 — 직전 생산량·날씨의 추가 예측 정보

작성: 2026-09-26. [001의 두 번째 후속 질문](09.26_001_power_models.md)과 [EDA 007의 조건별 관계](../../../EDA/jsw/reports/09.23_007_connected_eda.md)에서 출발했다.

## 이전 근거 → 질문·선택

001은 전력 18개와 달력 8개만 썼다. EDA 007에서 직전 생산량과 전력의 관계는 남았지만, 날씨 관계는 기간·조건에 민감했다. 이미 전력과 달력을 아는 모델에서 **직전 기록의 생산량·기온·풍속·습도·강수량이 더 도움이 되는가**를 확인했다. [실행 전 설정](../tables/09.26_003_frozen.json)대로 001의 트리 설정·두 개발 분할을 유지하고 생산량만, 날씨 4개만, 둘 다를 추가했다. 목표 시각의 생산량·날씨는 넣지 않았고 다른 시차·설정은 탐색하지 않았다.

## 데이터와 방법

001과 같은 5월 744시간·6월 720시간, 평균·최대 목표를 비교했다. 과거 값은 행 순서가 아니라 정확히 1시간 전 시각의 원본에서 찾았다. 1~4월 학습 2,712행, 1~5월 학습 3,456행이다. 생산량에는 결측이 없었다. 직전 풍속 3건·강수량 1건의 원본 결측이 있었다. 개발 평가에서는 6월 2시간이 영향을 받았다. 공통 시각을 유지하기 위해 결측을 임의 대체·행 삭제하지 않고 HGB의 결측 처리 기능에 맡겼다. [확보 수](../tables/09.26_003_coverage.csv).

| 목표·방법 | 5~6월 합산 MAE | 5월 MAE | 6월 MAE |
|---|---:|---:|---:|
| 평균 — 기존 전력+달력 | 4.621 | 5.193 | 4.030 |
| 평균 — 생산량 추가 | 4.618 | 5.172 | 4.045 |
| 평균 — 날씨 추가 | 4.644 | 5.120 | 4.152 |
| 평균 — 둘 다 추가 | 4.736 | 5.182 | 4.274 |
| 최대 — 기존 전력+달력 | 5.268 | 5.950 | 4.562 |
| 최대 — 생산량 추가 | 5.191 | 5.790 | 4.572 |
| 최대 — 날씨 추가 | 5.395 | 6.075 | 4.692 |
| 최대 — 둘 다 추가 | 5.333 | 5.895 | 4.753 |

생산량 추가의 합산 개선은 평균 0.003, 최대 0.077에 그쳤고 6월에는 두 목표 모두 약간 악화됐다. 날씨 단독·둘 다 추가는 합산 MAE가 악화됐다. 최대값의 높은 전력 지속 33시간에서 기존 MAE 4.40, 생산량 4.66, 날씨 4.94, 둘 다 5.37이었다. 높은 전력 시작 46시간에서도 기존 8.57보다 세 후보 모두 나빴다. [전체·상태·월별 점수](../tables/09.26_003_scores.csv), [행별 예측](../predictions/09.26_003_development_predictions.csv).

## 판단 갱신 → 다음 작업

직전 생산량은 전체 MAE에 작은 개선이 있으나 월별 방향이 엇갈리고 고전력 상태의 개선도 없어, 현재 근거만으로 일반적인 추가 정보로 채택하지 않는다. 날씨 역시 채택 근거가 없다. 특정 월에만 좋은 결과를 반복 하루 패턴이나 운영 원인으로 단정하지 않는다. 같은 입력을 더 세분하거나 다른 시차를 계속 시도해 결론을 맞추지 않고 이 질문을 종료한다. 관측 도착 시각과 생산량·날씨 정의가 확인되면 입력 가능성부터 다시 판단한다. 002의 높은 전력 놓침 변화는 [004](09.26_004_high_hour_selection.md)에서 별도로 집계했다.
