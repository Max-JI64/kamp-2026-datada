# HTML 시안 검증 · 16장

- 현재 구성: 표지·결론을 포함한 16장, 별도 부록 없음. 기존 12장·26장 시안은 archive에 보존했다.
- 내용: 데이터 진단, 하루·월별 구성, 낮은 전력·15분 배열, 생산 전환, 날씨·마지막 값, 평가 설계, 기본 모델, 사건 정의·결합, 오류 진단, 성능, 실패 사례, 활용, 재현성과 결론을 배치했다. 상세 조건은 발표·제작 메모에도 보존했다.
- 데스크톱: 1280×720에서 16장의 요소 경계·본문 형제 요소 겹침·텍스트 가로 넘침 검사 0건. 내장 그림 3개 정상 표시. 전체 페이지를 실제 화면으로 확인했다.
- 모바일: 390×844에서 같은 검사 0건, 16:9 비율 유지. 고정 슬라이드를 축소하며 내용을 재배열하지 않는다. 검사 후 화면 크기 설정을 원래대로 돌렸다.
- 기능: 슬라이드 선택과 번호 표시, 발표·제작 메모 열기·닫기를 확인했다. 16장 편집 저장 키를 분리해 이전 시안의 문구가 새 페이지에 덮어쓰이지 않게 했다.
- 출처: 8개 출처 파일의 현재 해시와 목록 일치, 사용한 그림 3개와 복사본 해시 일치. 12장 보관본의 기존 출처 해시와 비교해 원고 변경 없음을 확인했다.
- 재현성: 현재 제출 노트북의 코드 셀 25개 모두 실행 번호가 있고 저장된 오류 출력은 0건이다. 현재 제출/output/22_재현검증.csv의 정상 5,784시간·분류 1,428개·회귀 4,032개·최종 예측 1,344행을 반영했다. 회귀 최대 대조 차이는 약 8.53×10⁻¹⁴다. 이전 검증 요약 파일은 별도 작업으로 이동하여 현재 검증표를 연결했다.
- 작업 범위: 기존 분석·모델 결과를 재사용했다. 이번 HTML 작성에서 분석·학습·노트북을 재실행하지 않았다. 저장된 실행 결과 확인과 이번 화면 검증을 구분한다.
- 미검증: 실제 PPT 배치·발표시간·PDF 출력·외부 제출·현장 절감 효과. 이 HTML은 사용자의 PPT 제작 참고 시안이다.
