# HTML 시안 검증

- 현재 구성: 부록 없이 12장. 첫 26장 시안은 archive/26장_시안에 보존했다.
- 압축 방식: 배경·선택 이유·목표를 한 장으로 통합, EDA와 Analysis 각각 한 장으로 축약, 상세 수치·보조 설명은 제작 메모로 이동했다.
- 브라우저: 전체 12장의 요소 경계·표와 문구의 가로 넘침 검사 결과 0건. 내장 그림 3개 정상 표시.
- 화면: 배경·목표, 성능, 오류 사례를 실제 화면에서 확인했다. 성능·오류 사례는 1280×720에서도 확인했다.
- 모바일: 390×844에서 전체 요소 경계·가로 넘침 검사 결과 0건, 16:9 비율 유지. 화면을 휴대폰에 맞춰 다시 배열하지 않고 슬라이드 전체를 축소한다.
- 근거: 기존 압축 원고의 결과를 재사용했다. 모델 재실행이나 새 분석은 수행하지 않았다.
- 미검증: 실제 PPT 배치·발표시간·PDF 출력·제출 여부. 이 HTML은 사용자의 PPT 제작을 위한 참고 시안이다.
