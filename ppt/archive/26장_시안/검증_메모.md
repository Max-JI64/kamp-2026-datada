# HTML 시안 검증

- 구성: 본편 24장·부록 2장, 고정 1920×1080 슬라이드.
- 브라우저: 1280×720에서 전체 26장의 요소 경계와 본문 블록 겹침 검사. 발견한 배치 문제를 수정한 뒤 검사 결과 0건.
- 세부 문구: 390×844에서 전체 편집 대상·표·캡션의 가로 넘침과 푸터 침범 검사 결과 0건. 슬라이드 비율 16:9 유지.
- 화면 확인: 표지, 과제 선택, 하루 패턴 그림, 시간순 검증, 성과표, 활용, 결론과 휴대폰 과제 선택 화면을 확인했다. 모든 장의 개별 스크린샷을 확인한 것은 아니다.
- 기능: 슬라이드 선택·이전/다음 이동과 발표·제작 메모 표시를 확인했다. 문구 편집·다운로드·인쇄 기능의 실제 파일 저장은 별도 실행하지 않았다.
- 근거 파일: 원고·양식 7개와 그림 복사본 8개의 SHA-256 대조에서 불일치 0건. 새 데이터 분석·모델 재학습은 수행하지 않았다.
- 미검증 범위: 실제 PPT의 배치·발표시간·PDF 생성 및 페이지 수, 제출 여부. HTML은 PPT 제작용 구성 시안이다.
