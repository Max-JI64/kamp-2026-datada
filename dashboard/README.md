# 전력 흐름 전체 기간 시연

## 16:9 가로 화면

사용자 요청에 따라 1600×900의 16:9 화면으로 재배치했다. 왼쪽 약 70%는 큰 그래프와 선택 보완 설명, 오른쪽은 분석 KPI·경고/최근 예측·입력/판단 기여/날씨다. 현재 지표와 재생 조작은 상단, 사례와 시점 이동은 하단 한 줄에 있다. 창 크기에 맞춰 화면 전체를 같은 비율로 축소·확대하며 16:9보다 다른 비율의 창에는 여백을 둔다. 세로 스크롤을 사용하지 않고 해석 설명은 아래에서 열리는 창으로 확인한다.

기존 세로 화면은 `archive/v2_vertical`에 보존했다. 이번 변경은 내장 데이터를 그대로 재사용했고 모델 실행은 0회다. `repack_layout.cjs`로 HTML을 다시 묶었으며 `레이아웃_검증.json`에 데이터 동일 해시를 기록했다. `verify_demo_v2.cjs`에서 1920×1080·1600×900·1440×810·1366×768·1280×720·1024×768의 화면 맞춤 비율과 Canvas 좌표를 검증했다. 이 검사는 실제 브라우저의 텍스트/요소 경계 시각 검증을 대체하지 않는다.

현재 화면 소스는 `template_wide.html`·`style_wide.css`·`app.js`다. `build_demo.py`도 이 소스를 사용한다. 배치만 바꿀 때는 `repack_layout.cjs`를 사용해 모델 재실행을 피한다.

`전력_흐름_시연.html`을 열고 **재생 시작**을 누른다. HTML 파일 하나만 복사해도 된다. 브라우저에서 모델·서버·인터넷을 사용하지 않는다. 기존 저장 모델의 추론은 HTML 제작 때 한 번 수행했다.

## 화면

- 2021년 1월 1일부터 9월 14일까지 전체 원자료를 재생한다. 15분 값 하나를 기본 1초에 공개한다. 날짜 전환으로 멈추거나 그래프를 초기화하지 않는다.
- 최근 6·12·24시간분 관측을 유지하고, 예측을 같은 시간축의 빨간 점선으로 이어 보인다. 예측구간은 빨간 음영이다. 15분별 미래값을 예측한 선이 아니라 대상 시간 전체 최대값의 예측 표시다.
- 정상 자료가 없는 48시간의 공백은 건너뛰되 이전 관측은 유지한다. 점선 연결과 자료 공백 문구는 불연속 경계 표시이며, 사이의 관측값을 생성한 것이 아니다. 가로축은 관측 순서를 사용하므로 공백 시간은 압축된다.
- 상단은 현재 관측·증감·예측·경고를 보여주는 운영 지표다. 별도의 **분석 검증 KPI**에는 전체 MAE, 상승 과소예측 감소, 정밀도, 재현율을 표시한다.
- 중복된 ‘예측 확인’ 패널을 없애고 **지속 상승 경고 때만 B1 보완 예측으로 전환**하는 과정과 기본·적용 예측 차이를 보여준다. 이 선택적 보완이 보고서의 핵심 방법이다.
- 직전 전력·과거 6시간 중앙값·직전 생산량·달력 조건을 표시한다. 상승 Logistic의 표준화 입력×계수 로짓 분해를 과거 전력·달력·생산·상태의 네 군으로 합산해 판단 근거를 보여준다. HGB의 변수 중요도나 전력의 인과적 영향률로 쓰지 않는다.
- 직전 완료 시간의 날씨를 참고 조건으로 보여준다. 기온의 단순 순위 관계 +0.227은 조건을 고려하면 −0.004였으며 최종 모델에는 날씨가 없다. 날씨의 예측 개선 비교는 미실행이므로 날씨가 무용하다고 주장하지 않는다.

## 급등·급락과 사례

급등·급락과 지속 상승·하락은 기존 분석에서 다뤘다. 기존 개발 하락 HGB는 4~6월 지속 하락 15건 중 8건을 찾고 오경보 10건이 있었다. 최종 상승 보완과 같은 수준으로 검증·정리된 운영 모델은 아니었다.

이번 화면은 다음을 구분한다.

- **급등·급락 관측:** 완료된 시간의 평균 전환을 기존 S01 정의로 표시한다. 상승 기준 59.5, 하락 기준 42.925와 과거 중앙값·IQR 조건을 함께 사용한다. 모든 15분 튐을 이 사건으로 부르지 않는다.
- **지속 상승 경고:** 기존 최종 noage Logistic 점수와 경계 0.4554612321을 사용한다. 경고 때 B1으로 전환한다.
- **지속 하락 경고:** 기존 5월 말 학습 HGB와 6월 적용용 과거 OOF 경계 0.3522447142를 재사용한 실험적 시연이다. 이번에 새 모델 선택·튜닝·성능 채택을 하지 않았다.

사례 버튼은 지속 상승 경고·선택 보완(7/12 07:45), 지속 하락 경고(6/5 06:45), 큰 급등 관측(3/21 07:45), 평상 기본 예측(1/4 12:00)이다. 경고 사례는 한 번 15분 이동하거나 재생해 대상 시간 시작을 확인한다. 사용자 요청에 따라 미탐지·시간 오류 사례 버튼은 제외했다.

## 전체 기간 예측의 해석

이전 시연은 최종 저장 예측 1,344시간만 넣었고 7/12 직전부터 시작해, 7/13 시간 오류 구간이 빠르게 나타났다. 사용자는 전체 기간 재생과 예측 확장·연속 그래프·선택 보완과 입력 설명·KPI를 요청했다. 기존 자료와 모델을 보존하고 HTML 제작용 최소 추론만 추가했다.

전체 정상 6,120시간을 표시한다. 기본 모델 추론은 6,114시간이고, 필수 시차가 부족한 3시간은 직전 시간 최대값 기준, 이전 시간 자체가 없는 3시간은 화면의 최근 관측 기준으로 구분한다. 처음부터 존재하지 않는 과거를 만들어 학습하거나 모델 예측구간을 붙이지 않는다.

**1~6월 예측은 6월까지 학습한 최종 모델을 과거에 적용한 시연이다.** 이 값은 독립 검증 성능이나 당시 실제 운용 예측이 아니다. 7~8월 기존 공통 예측 1,344개와 상승 점수 1,428개는 1e-10·1e-12 허용오차에서 일치했다. 추가된 시간과 9월의 예측은 시연용 추론이며 새 평가 성과로 제시하지 않는다. KPI는 원래 평가와 같은 범위·수치를 유지한다.

시간 h의 네 값은 h:15·h:30·h:45·다음 정각에 공개한다. 예측은 대상 시간 시작에 공개한다. 시간 최대값은 해당 시간의 관측 네 개가 완료된 뒤에만 이력에 공개한다. 시간 배치는 시연 규칙이며 실제 계측 완료 시각은 미식별이다. 모든 자료가 내장되므로 브라우저 개발 도구에서 미래 자료를 읽는 것까지 차단하는 보안 시스템은 아니다.

## 예측구간과 검증 KPI

5~6월 저장 개발 예측 1,462개의 절대오차 90% 순위값을 사용한 **예측±12.5727089064**를 유지했다. 기존 7~8월 공통 1,344시간의 포함률은 1,123/1,344=83.56%다. 추가 시연 구간의 구간 포함률은 미검증이다. 개발 자료 재사용·시계열 의존성 때문에 미래 포함률 90%를 보장하지 않는다. 모수의 신뢰구간이나 15분 값별 범위가 아니다.

KPI는 7~8월 공통 평가의 전체 MAE 6.317, 상승 과소예측 15.8% 감소, 상승 정밀도 7/7=100%, 재현율 7/13=53.8%를 사용한다. 선택 보완은 일부 지속 상승에서 제한된 성과이며 실제 가동 조정·자동 제어·비용 절감은 미측정이다. 전력 원단위는 미식별이므로 kW·kWh를 붙이지 않았다.

## 파일과 실행 검증

- `build_demo.py`: 전체 원자료 내장 및 HTML 생성.
- `prepare_full_replay.py`: 저장 모델 4개를 로딩해 재학습 없이 전체 기간 추론·로짓 분해·원래 예측 대조. 정규 CPython 3.13로 실행했다.
- `template_v2.html`, `style.css`, `app.js`: 화면 소스. 빌드하면 CSS·JavaScript·JSON을 모두 최종 HTML에 내장한다.
- `full_period_inference.json`: 제작 때 계산한 시연용 예측·판단 기여·사례·검증. HTML 실행에 별도로 필요하지 않다.
- `검증_결과.json`: 입력·모델·계약 해시, 원자료 최대값 대조, 예측구간, 추론 범위.
- `verify_demo_v2.cjs`, `HTML_동작검증.json`: 내장 JavaScript 실행 검증. 시작일·날짜 전환·공백·9월·경고·선택 보완·미래 실제 최대값 비공개·전체 24,480개 관측 시점의 예측 공개 조건을 확인했다. 1,320·768·366px의 Canvas 연산 유한성도 확인했다.
- `archive/v1`: 수정 전 시연 보존본.

정규 Python 생성과 Node 동작 검증의 종료 코드는 0이다. 브라우저 도구의 로컬 파일 접근 정책 때문에 실제 브라우저 화면의 시각·레이아웃 검증은 미완료다. Node DOM·Canvas 테스트 어댑터 검증을 브라우저 렌더링 검사로 해석하지 않는다.

원자료·모델·분석 원고·기존 결과는 수정하지 않았다. 이번 질문은 전체 기간 시연과 분석 핵심의 화면 반영으로 해결했고, 이를 새 분석 성능 주장으로 확대하지 않는다.
