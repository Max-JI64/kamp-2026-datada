# 전력 흐름 시연

`전력_흐름_시연.html`을 브라우저에서 열고 **재생 시작**을 누른다. HTML 파일 하나만 복사해도 동작한다. 서버·인터넷·Python·모델 파일이 필요하지 않다. HTML을 열 때 모델이 실행되거나 학습되지 않는다.

## 화면과 조작

- 기본 속도는 1초에 15분 관측 하나다. 0.5·1·2·4배 속도를 선택할 수 있다.
- 날짜·전체 시점 슬라이더·사례 버튼으로 이동한다. 최근 6·12·24시간의 관측을 볼 수 있다.
- 현재 전력값, 직전 15분 대비 증감, 시간 최대값 예측, 지속 상승 경고를 표시한다.
- 오른쪽 음영은 **대상 시간 전체 최대값의 예측구간**이다. 15분 값 네 개의 미래 궤적이나 개별 값의 범위를 예측한 것이 아니다.
- 15분 관측은 1초마다 공개하지만 예측은 매시간, 즉 기본 속도에서 4초마다 해당 시간의 저장 결과를 공개한다.
- 기본 화면은 7월 12일 07:45다. 한 번 이동하면 08시 지속 상승 경고와 보완 예측을 볼 수 있다.
- 한 시간이 완료되기 전에는 해당 시간의 실제 최대값을 이력에 표시하지 않는다.

## 내장 자료와 범위

전체 원자료 `data/origin/okm_augumented_2021.csv`의 6,168행·18열을 HTML에 내장했다. 시간 오류 48행은 원자료 배열에 보존하되 그래프에서 제외한다. 정상 6,120시간을 24,480개의 15분 값으로 펼쳤다. 관측 범위는 1월부터 9월 14일까지이며, 시간 h의 슬롯을 h:15·h:30·h:45·다음 정각 순서로 재생한다. 이는 시연의 시간 배치 규칙이며 실제 계측 완료 시각을 검증한 것은 아니다.

예측은 기존 최종 조합 `G1_noage`의 7~8월 적격 1,344시간을 재사용한다. 상승 점수·경고는 `noage` 1,428시간을 내장한다. 관측이 있어도 예측이 저장되지 않은 시각에는 예측 없음으로 표시한다. 누락 예측을 다른 값으로 채우거나 과거 예측으로 연장하지 않는다. 브라우저가 가진 원자료 중 미래 값은 현재 관측·이력·툴팁에 공개하지 않는다. 모든 자료가 내장된 시연이므로 보안상 미래 자료 접근을 막는 시스템은 아니다.

전력 원단위는 현 자료에서 미식별이므로 kW·kWh로 표기하지 않았다. 상승 점수는 확률 보정 전 출력이다. 경고는 분석의 큰 상승 후 3시간 유지 사건에 대한 것이며, 모든 급등·설비 한계 초과·안전 판정을 뜻하지 않는다. 미래 하락 위험은 이번 화면에 포함하지 않았다.

## 예측구간 분석과 판단

이전 근거는 보고서 제4장의 ‘다음 시간 최대값과 지속 상승 경고를 함께 확인’하는 활용안과, 최종 `G1_noage`의 저장 예측이다. 사용자 요청에 따라 모델을 실행하지 않는 HTML에서도 불확실성을 보여줄 수 있는지 확인했다.

선택한 최소 계산은 5~6월 시간순 개발 예측 1,462개의 절대오차를 정렬한 뒤 `ceil((1462+1)×0.90)=1317`번째 값을 고정해 7~8월에 적용하는 것이다. 결과를 본 뒤 구간 폭을 넓히거나 다른 구간 방법을 탐색하지 않았다. 모델 재학습·추론은 수행하지 않았다.

- 구간: 기존 예측값 ± **12.5727089064**. 구간을 임의로 잘라내지 않았다.
- 7~8월 포함률: **1,123/1,344 = 83.56%**.
- 판단: 90%를 목표로 정한 경험적 예측구간과 실제 포함률을 함께 표시한다. 현재 범위가 미래 최대값을 항상 포함한다는 설명은 하지 않는다.
- 한계: 개발 자료는 모델 선택에 이미 사용됐고, 시계열 관측은 독립 표본이 아니다. 탐색적 구간이며 미래 포함률 90%의 통계적 보장은 없다. 모수의 신뢰구간과도 다르다.
- 종료 근거: 저장 예측으로 범위를 만들 수 있다는 질문에 답했고, 포함률 한계도 확인했다. 이번 시연 범위에서는 구간을 개선하기 위한 새 모델·경계 탐색을 수행하지 않는다.

## 생성과 검증

- `build_demo.py`: 원자료·저장 예측을 읽어 단일 HTML과 `검증_결과.json`을 만든다. 정규 CPython 3.13에서 종료 코드 0으로 실행했다.
- `template.html`: 데이터가 들어가기 전 화면 소스다. 배포할 때에는 완성된 HTML만 필요하다.
- `검증_결과.json`: 입력 해시, 구간 방법, 포함률, 원자료 최대값 1,344건 대조 결과다.
- `verify_demo.cjs`: 내장 JavaScript를 Node의 DOM·Canvas 테스트 어댑터에서 실행한다.
- `HTML_동작검증.json`: 재생·이동·누락·시간 경계·미래 실제값 공개 제한·외부 네트워크 호출 없음 등의 검사 결과다. 전체 24,480개 시점의 예측 공개 조건을 확인했다.

브라우저 도구가 로컬 `file:` 주소를 보안 정책으로 차단해 실제 브라우저의 시각·레이아웃 검증은 하지 못했다. Canvas 그리기 코드의 1,320·768·366px 폭 실행은 확인했지만 실제 브라우저 렌더링 검사로 해석하지 않는다.

재생 파일을 다시 만들 필요가 있을 때에는 프로젝트 지침의 정규 Python 3.13 실행 경로로 `dashboard/build_demo.py`를 실행한다. 기존 원자료·모델·보고서는 수정하지 않았다.
