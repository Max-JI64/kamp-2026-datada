# EDA: jsw

원본 구조·분포·기록 형태를 확인하는 단계다. 예측 모델과 오류 평가는 `../../modeling/jsw`, 피크 관리 해석과 시나리오는 `../../analysis/jsw`에서 다룬다. [작업 규칙](AGENTS.md)을 따른다.

[M008 생산조건별 예측 오류 비교](../../modeling/jsw/reports/09.29_008_production_error_comparison_plan.md)는 E003의 487 경계와 생산량 증감 정의를 재사용해 저장된 7~8월 예측의 HGB·기준선을 같은 1,344시간에서 비교했다. E003 기준선 생산조건 36행을 재현했으며 EDA 자체의 집계·결론은 변경하지 않았다.

[A049 본문용 핵심 결과](../../analysis/jsw/reports/09.29_049_core_findings_report_plan.md)는 기존 A003·A033~037의 저장 표로 전체/조건별 평균과 같은 조건 안 상위값 빈도, 생산 전환의 시각 구성 차이를 정리했다. EDA 원본 집계나 E025 결론은 바꾸지 않았다.

- [프로젝트 전체 로드맵](../../09.29_004_프로젝트_목표와_실행로드맵.md)
- [E025 정확 평균·최대 차이와 입력 중복](reports/09.29_025_peak_gap_eda_plan.md): Q1의 부족한 시간별 정확 평균 집계·검증 완료, Q2는 M001 명세·코드 재사용으로 종료. 1~6월 D 중앙값 5.5, 같은 A에서도 최대가 달랐다. 기존 187 기준의 M 가림 194/287과 A 가림 202/287을 분리한다. P·직전 R·마지막 칸은 기존 입력이다. M005가 지속 부족량을 주 실패로 선정해 M006은 S 특징을 추가하지 않고 단일 혼합 후보를 비교했다. E025 자체는 모델 학습·성능 비교가 아니다.
- [E024 집중도·월최대 위치·저부하 안정성](reports/09.28_024_guidebook_domain_interpretation.md): 세 질문 모두 계산 완료. 단일 기저값 가정은 기각.
- [E023 생산 기록 형태](reports/09.28_023_production_record_shape.md): 정상 241일 중 181일의 날짜 안 다중 생산값 확인. 실제 ERP 배분·확정 시점은 현 자료에서 미식별.
- [E020 기존 EDA 종합](reports/09.23_020_eda_review.md): 당시 질문·결과 이력. 이후 정의와 자료 경계는 E023·E024 및 현재 루트 규칙을 적용.
- [실행 이력](LOG.md)

현재 `data` 폴더가 제공 자료의 전부다. 추가 자료 대기는 후속 조건이 아니다. E025는 기존 결과로 답할 부분을 재사용하고 필요한 기술통계만 실행했다. Q1·Q2 종료와 이후 모델링·경보·시나리오 완료는 구분한다. E025는 M005의 선행 필수 작업이 아니다.

[최종 통합 보고서](../../09.29_005_최종_통합_결론과_마무리_계획.md)는 E025의 관측 결과를 A045의 시나리오, M005~007의 예측·경보 평가와 연결한다. 각 단계의 실행 완료와 전체 재현·제출 준비 상태를 구분한다.
