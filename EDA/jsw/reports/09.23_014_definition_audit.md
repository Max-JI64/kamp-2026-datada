# 14차 자료 점검: 13차 EDA를 해석하는 데 필요한 정의는 어디까지 확인됐나

작성일: 2026-09-23 | 작업 번호: 09.23_014 | 성격: 문서·출처 점검(새 수치 계산 없음)

## 1. 왜 확인했나

[13차 EDA](09.23_013_zero_production.md)에서는 생산량 0인데 전력이 기록된 시간, 하루 전력 기록이 같은데 생산량이 다른 날짜, 전력과 생산량이 함께 0인 17시간을 확인했다. 이 현상의 **원인**을 말하려면 각 열의 수집·집계 정의가 필요하다. 사용자는 `data` 폴더 외에 원본 가이드북이 없을 가능성을 알려줬다. 이번에는 새 통계를 만들지 않고, 현재 확보한 자료와 공식 배포처에서 **확인된 사실과 확인되지 않은 정의**를 구분했다.

프로젝트의 `data/origin`에는 위 CSV·개요·변수 진단표 세 파일만 있었다. 프로젝트 전체 파일명 검색에서도 이 자료의 원본 가이드북 PDF/HWP는 확인되지 않았다. 대회 과제공개 HWPX는 과제 요구사항 자료이지 이 CSV의 열별 수집 정의서가 아니다. 공식 사이트 검색에서도 다른 데이터셋의 가이드북이 나왔지만, 이름이 비슷하다는 이유로 이번 데이터에 적용하지 않았다.

## 3. 13차 결과와 정의의 경계

| 13차에서 실제 확인한 것 | 추가로 필요한 정의 | 지금의 판단 |
|---|---|---|
| 1~8월 정상 시각에서 생산량 0인 2,507시간 중 2,490시간에 평균 전력이 양수 | 생산량 0이 계획 0인지 실적 0인지, 어떤 제품·공정을 합산했는지; 변압기 전력이 어느 설비를 포함하는지 | `생산량 0 = 공장 정지` 또는 `낭비전력`으로 명명하지 않음 |
| 2021-03-01은 하루 생산량 합계 0인데, 2021-02-01·06-01은 **하루 96개 전력값이 03-01과 모두 같고** 생산량 합계는 각각 20,368·17,704 | 날짜·전력·생산량이 어떤 규칙으로 결합·증강됐는지; 생산량의 측정 범위와 시간 기준 | 동일 전력에 다른 생산량이 붙는 사실만 확정. 오류·정상 운전·증강 중 어느 이유인지 미확인 |
| 2021-08-28 18시~08-29 10시의 연속 17시간은 전력 네 값과 생산량이 모두 0이며 `공장인원`은 비어 있음 | 실제 가동·정전 여부, 계측기의 결측 표기 규칙, `공장인원`의 공식 생성식 | 실제 정지 또는 계측 누락으로 판정하지 않음. [기존 변수 진단](../../../data/origin/데이터_변수표.md)은 `공장인원`이 생산량/전력 네 값 합계와 일치함을 발견했으나 공식 이름의 의미는 미확인 |
| 2021-07-13·07-15에는 `시간`이 0~23을 벗어난 48행이 있음 | 원본 시간 표기의 오류 여부와 정정 자료 | 행 순서로 시간을 복원하지 않음 |

특히 개요의 **“변압기 센서·15분 단위”** 설명은 전력 열의 출처를 일부 알려줄 뿐, 생산량과 같은 공정·설비·시각을 측정했다는 근거는 아니다. 따라서 13차의 관찰 결과는 유지하되 운영 원인 해석은 확대하지 않는다. 표의 수치는 기존 [11차 날짜별 표](../tables/09.23_011_daily_profile_summary.csv), [13차 결과표](../tables/09.23_013_high_profile_counterparts.csv)와 [13차 보고서](09.23_013_zero_production.md)에서 재사용했다.

## 4. 데이터 제공처에 물어볼 내용

우선 **이 CSV와 정확히 대응하는 원본 가이드북 또는 데이터 명세서가 있는지** 확인한다. 있다면 버전과 제공 경로도 함께 받는다. 없으면 다음 네 질문의 답만 받아도 13차 해석을 갱신할 수 있다.

1. `생산량`의 단위와 대상 공정·설비는 무엇인가? 각 행의 값은 **그 시간의 실제 생산 실적, 생산 계획, 누적값 중 무엇인가?** `0`은 어떻게 기록되는가?
2. `15분·30분·45분·60분`은 **kW·kWh 등 어떤 단위**이며 순간값·구간 평균·구간 사용량 중 무엇인가? `시간=8`인 행은 정확히 어느 시각부터 어느 시각까지인가? 변압기 측정 범위는 생산량 집계 범위와 같은가?
3. 파일명 `okm_augumented_2021.csv`의 **증강 방식**은 무엇인가? 특히 2021-02-01·03-01·06-01처럼 하루 전력값 96개가 같고 생산량은 다른 날짜가 실제 별도 관측인지, 복제·합성·재결합된 기록인지?
4. 2021-08-28 18시~08-29 10시 전력 0·생산량 0과 `공장인원` 결측은 실제 운영 상태인가, 센서/결합 문제인가? 2021-07-13·07-15의 비정상 `시간` 48행에 정정 원본이 있는가?

문의 시 **파일명**, 날짜별 사례, 필요한 정의를 함께 제시한다. 답변이 특정 데이터셋의 공식 자료인지 파일명·열 구성·기간으로 먼저 대조해야 한다. 다른 KAMP 전력 데이터셋의 설명을 이번 CSV의 정의로 옮기지 않는다.

## 5. 판단과 다음 작업

**확인된 사실:** 현재 로컬 자료에는 원본 가이드북 전문이 없다. 개요는 변압기 센서의 15분 수집만 설명한다. 숫자로 확인한 13차 관찰은 그대로 유효하다.

**남은 질문:** 생산량과 전력의 단위·범위·시간 연결, 반복 날짜의 생성 방식, 전력 0 구간의 실제 상태는 아직 구분할 수 없다. 공식 사이트 검색에서 일치하는 가이드북을 못 찾은 것은 **접근하지 못했다는 결과**이지 가이드북이 없다는 확정은 아니다.

**다음 작업:** 데이터 제공처의 답변이나 원본 명세서를 받으면 위 네 질문별로 `문서 내용 → 11~13차의 실제 기록 → 유지/수정할 해석`을 대조한다. 답변 전에는 **정의가 필요한 원인 질문을 해결하려고** 같은 임계값·상관을 반복 계산하지 않는다. CSV만으로 답할 수 있는 별개의 기록 형태 질문은 진행할 수 있다. 이 자료 정의 점검은 여기서 마친다. 9월 보류와 모델·예측·경보 분석 범위는 그대로 둔다.
