# 8차 EDA: 고전력 시작 전 3시간에 관측된 변화

작성일: 2026-09-23 | 작업 번호: 09.23_008

## 목적과 이전 근거

[7차 EDA](09.23_007_connected_eda.md)에서 전력의 1시간 시차 상관은 0.902였다. 그러나 [3차 기준선](09.23_003_baselines.md)은 고전력 시작에서 과소예측했다. 직전 전력 수준과 1~3시간 전 변화가 시작 구간을 구분하는지 확인했다.

## 범위와 방법

- 원본 1~8월 중 정상 시각 5,784행을 사용했다. 1~6월을 학습기간, 7~8월을 검증기간으로 구분하고 9월은 보류했다.
- 3차에서 **학습기간만으로 산정한 15분 최대 전력 95백분위수 182**를 그대로 사용했다. 직전 시간의 최대 전력이 182 미만이고 현재 182 이상이면 `고전력 시작`이다. 이 기준은 탐색용이며 운영 경보 기준이 아니다.
- 현재 구간의 1·2·3시간 전 시각이 정확히 존재하는 기록만 비교했다. 직전이 비고전력인 기록 중 학습 **4,106행·시작 139건**, 검증 **1,214행·시작 85건**이 남았다. 시작 아닌 기록도 같은 이력 조건을 적용했다.
- 시작·비시작의 이전 전력·생산량을 먼저 비교하고, 월×현재 시간×평일/주말이 같은 셀에서 비시작 평균과 비교했다. 224건 중 **221건**에 비교 대상이 있었다. 검증기간 3건은 같은 셀에 비시작이 없어 조건 비교에서 빠졌지만 전체 집계에는 유지했다.
- 발생 시점의 전력 변화와 생산 시작은 **사후 설명**이다. 예측 시점에 이용 가능한 신호로 해석하지 않는다. 생산량의 실제 기록·계획 여부도 미확인이다.

## 결과: 평균보다 시간대별 방향이 중요했다

| 월·시간 조건 일치 비교 | 학습 시작 139건 | 검증 시작 82건 |
|---|---:|---:|
| 시작 직전 평균 전력 | 123.28 | 134.70 |
| 같은 셀 비시작의 직전 평균 전력 | 94.34 | 107.31 |
| 차이 | **+28.94** | **+27.39** |
| 시작 직전 전력 변화¹의 차이 | -0.13 | +3.79 |
| 현재 전력 점프²의 차이 | +33.70 | +23.08 |

¹ `t-1` 평균 전력 − `t-2` 평균 전력. ² `t` 평균 전력 − `t-1` 평균 전력. 값은 시작 건수로 가중한 셀별 평균 차이다. 전력 단위는 원본에서 확인되지 않았다.

같은 조건에서 시작 전 전력 **수준**은 더 높았다. 그러나 직전 한 시간의 **상승폭**은 기간 전체를 합치면 비시작과 거의 구분되지 않는다. 이 결과만으로 사전 추세가 없다고 판단하면 중요한 시간대 차이를 놓친다.

| 시작 시각 | 학습: 직전 상승 / 시작 | 검증: 직전 상승 / 시작 | 시작 직전 전력 변화 평균: 학습 / 검증 |
|---|---:|---:|---:|
| 8시 | 45/46 | 31/31 | +23.9 / +27.7 |
| 13시 | 0/48 | 0/20 | -63.4 / -75.2 |

8시 시작은 직전 상승 뒤에, 13시 시작은 직전 하락 뒤에 관측됐다. 13시의 현재 전력 점프 평균은 학습 **+68.7**, 검증 **+67.3**이다. 이 패턴의 실제 공정 원인은 확인되지 않았다. 두 시간대가 반대 방향이라 전체 상승폭 평균이 상쇄된다. 따라서 전체 평균으로 직전 상승의 유무를 결론 내렸던 초기 해석은 수정한다.

시간대별 비시작 기록도 포함한 분모는 [방향별 발생률 표](../tables/09.23_008_direction_hour_rates.csv)에 있다. 예를 들어 검증 8시의 직전 상승 40건 중 시작 31건, 검증 13시의 직전 하락 45건 중 시작 20건이었다. 탐색된 패턴이며 예측 정확도나 경보 성능은 아니다.

근거: [대상·사건 수](../tables/09.23_008_coverage.csv), [조건별 비교](../tables/09.23_008_matched_summary.csv), [시간대별 시작 형태](../tables/09.23_008_onset_transitions.csv), [개별 비교 셀](../tables/09.23_008_matched_strata.csv).

## 이 결과에서 이어진 질문

직전 상승폭은 시간대별로 방향이 반대였고, **직전 전력 수준은 두 기간 모두 시작 구간에서 높았다.** 그래서 다음에는 학습기간의 전력 수준 구간을 고정해 검증기간에도 시작 비율이 높아지는지 확인한다. 그 결과는 [9차 EDA](09.23_009_onset_level.md)에 기록했다.
