# 6차 EDA: 척도 비교를 조건별 관계와 반복 구조 분석으로 연결

작성일: 2026-09-23 | 작업 번호: 09.23_006

## 1. 이전 판단 정정과 이번 질문

5차 EDA에서 왜도 비교 후 ‘추가 반복이 불필요하다’고 결론 내린 것은 관계 탐색 목적에 불충분했다. 변환의 목적은 왜도를 낮추는 것 자체가 아니라 가려진 분포와 관계를 확인하는 것이다. 이번에는 대안 척도 → 0 분리·양수 분위수 → 시간대·요일 내 대비 → 동일 전력 패턴의 생산량·기상 차이까지 분석을 연결했다.

분석 범위는 1~8월 정상 시간 5,784행이다. 9월 보류를 유지하고 시간 오류 48행을 제외했다. 강수량 관련 집계는 결측 1개도 제외한다. 앞선 전체 분포표의 5,832행과 분모가 다르다. 원본 수정·이상치 제거·모델 학습·가설 검정·플롯 생성은 하지 않았다.

## 2. 다른 척도도 비교했지만 0 집중과 조건 차이는 남는다

원값, 제곱근, `log1p(x)=ln(1+x)`, `asinh(x)=ln(x+sqrt(x²+1))`를 비교했다. 모두 비음수 입력에서 순위를 보존한다. asinh는 작은 값에서는 원값에 가깝고 큰 값에서는 로그처럼 압축한다. 현재 기록 단위 기준 비교이며 척도 변경을 새로운 정보의 생성으로 해석하지 않는다.

| 대상 | 원값 왜도 | 제곱근 | log1p | asinh |
|---|---:|---:|---:|---:|
| 생산량 전체 | 3.272 | 1.196 | 0.096 | 0.047 |
| 생산량 양수 | 2.575 | 0.789 | -0.739 | -0.816 |
| 강수량 전체 | 7.995 | 3.620 | 2.616 | 2.480 |
| 강수량 양수 | 4.026 | 1.770 | 0.627 | 0.452 |

전체 생산량에서는 asinh의 왜도가 가장 작지만 양수만 보면 왼쪽 치우침이 더 커진다. 왜도 최솟값을 최적 변환으로 고르지 않았다. 양수 생산량의 10개 동일 폭 구간 중 가장 큰 구간 비중은 원값 69.18%, 제곱근 25.48%, 로그 26.37%, asinh 27.92%다. 제곱근도 양수 분포를 펼쳐 보는 데 유용하다. 이 비중은 구간 정의에 따른 기술통계이며 정규성 지표가 아니다.

강수량 전체는 어떤 척도에서도 0 집중이 남았다. 따라서 변환을 더 복잡하게 탐색하기보다 0과 양수를 나누고 양수를 분위수 구간으로 비교했다. Box-Cox 등 정규화 목적의 추가 변환 탐색은 이번 관계 질문의 필수 단계가 아니다.

근거: [척도별 분포와 관계](../tables/09.23_006_scales.csv).

## 3. 척도에 덜 의존하는 구간 비교로 관계 확인

양수 생산량을 사분위수로 나누면 전력 중앙값은 105 → 108 → 158.5 → 159다. 높은 생산량 구간일수록 전체 전력이 높아 보이지만, 위쪽 두 구간의 차이는 작고 분포는 겹친다. 단조 변환은 순위를 바꾸지 않으므로 분위수 그룹 비교는 어떤 로그 척도를 선택했느냐에 좌우되지 않는다.

다음으로 양수 생산 기록을 시간대×요일별로 나누고, 각 그룹 내부에서 생산량 하위 25%와 상위 25%의 전력 중앙값을 비교했다. 비교 기준은 그룹 12행 이상·생산량 고유값 4개 이상이다. 이는 소표본을 줄이는 편의 기준이지 통계적 유의성 기준은 아니다. 동률 경계값은 포함했다.

| 비교 결과 | 그룹 수 |
|---|---:|
| 생산량 높은 쪽의 전력 중앙값이 더 큼 | 60 |
| 같음 | 11 |
| 오히려 작음 | 49 |
| 합계 | 120 |

120개 그룹의 ‘상위 생산량 전력 중앙값−하위 생산량 전력 중앙값’의 중앙값은 **0.25**다. 각 그룹을 같은 가중치로 요약한 값이며 개별 행이나 전체 공장의 효과가 아니다. 양수 생산의 시간대·요일 그룹 평균 제거 상관도 원값 0.027, 제곱근 0.037, 로그 0.038, asinh 0.038로 모두 작았다.

따라서 **전체 관계를 단순히 생산량의 크기 효과로 설명하기 어렵다는 해석은 변환을 바꿔도 유지된다.** 관계가 전혀 없다는 뜻은 아니며 월·생산 종류·반복 패턴 등이 남아 있다. 이를 유의성 검정이나 인과효과로 해석하지 않는다.

강수량 양수 분위수 구간의 전력 중앙값은 101 → 115 → 98 → 93.5로 단조 증가하지 않았다. 각 구간의 생산량 양수 비율도 52.68% → 73.56% → 53.64% → 43.61%로 달라, 강수량과 전력만 비교한 차이에 생산 상태 구성이 섞여 있다. 강수량 0 구간의 전력 중앙값은 104다. 분위수 동률 때문에 구간 표본 수는 동일하지 않다.

근거: [0·양수 분위수 구간](../tables/09.23_006_rank_bins.csv), [시간대·요일 내 대비](../tables/09.23_006_within_strata.csv).

## 4. 같은 전력 패턴인데 생산량과 기온이 달랐다

날짜마다 24시간×전력 4열의 96개 값을 시각 순서대로 비교했다. 같은 원전력 하루 패턴이 여러 날짜에 나타나는 그룹은 45개다. 그중 **40개 그룹은 날짜별 생산량 합계가 달랐다.** 같은 패턴·같은 시간으로 묶은 1,080개 반복 그룹 중 880개는 생산량이 달랐다. 전력 4개 값이 그룹 안에서 정확히 같음을 코드로 검증했다.

| 같은 하루 전력 패턴의 사례 | 날짜 수 | 날짜별 생산량 합계 범위 | 일평균 기온 범위 |
|---|---:|---:|---:|
| 4/12~4/16 및 5/18 | 6 | 16,126~23,411 | 10.63~17.43 |
| 1/2·2/5·3/6·3/13·3/20·3/27·6/5 | 7 | 0~19,048 | -0.17~22.21 |

생산량 합계는 기록값의 날짜별 단순 합이며 생산량이 시간별 실적인지 공식 집계 정의는 미확인이다. 기온·전력의 물리 단위도 임의로 확정하지 않는다.

이는 생산량·기온의 변화가 항상 서로 다른 전력 기록으로 나타나지는 않는다는 구체적 증거다. 증강·복사나 인과관계 부재를 입증하는 것은 아니다. 데이터 생성 설명과 생산량·전력의 집계 범위를 확인해야 한다.

반복 횟수가 많은 패턴이 상관을 지배하는지도 추가 확인했다. 각 행에 `1/해당 패턴의 날짜 수` 가중치를 줬을 때 전체 생산량–전력 상관은 원값 0.520→0.538, 로그 0.766→0.784로 소폭 바뀌었다. 따라서 반복 빈도만 조정한다고 전체 관계가 사라지는 것은 아니다. 날짜 삭제나 새로운 전처리 기준으로 채택하지 않았다. 양수 부분집합에서는 같은 가중치를 유지하므로 패턴별 총 가중치가 동일하지 않을 수 있다.

## 5. 이번 분석으로 달라진 판단

- 변환 선택: 생산량 양수 분포는 제곱근과 로그를 보완적으로 볼 수 있다. 강수량은 0 여부와 양수 크기를 분리하는 것이 먼저다. 왜도 최적화는 목표가 아니다.
- 관계 해석: 전체 상관은 강해 보여도 같은 시간대·요일의 양수 생산량 안에서는 일관된 증가가 확인되지 않는다. 특정 변환으로 해결되는 문제가 아니었다.
- 데이터 이해: 같은 전력 패턴에 서로 다른 생산량·기온이 연결되는 구조를 확인했다. 공식 생성 방식 확인 전 생산량이나 기상을 전력 변화의 직접 원인으로 설명하면 안 된다.
- 다음 질문: 같은 전력 패턴과 다른 패턴에서 생산·비생산 상태 구성이 어떻게 달라지는지, 데이터 가이드에 증강·집계 방식 설명이 있는지 확인한다. 모델링 전환은 별도다.

이번 종료는 ‘왜도가 줄었다’가 아니라 대안 척도, 조건 내 대비, 반복 구조와 민감도까지 확인해 위 질문에 답했기 때문이다. 해결되지 않은 생성 방식은 미확인으로 남긴다.
