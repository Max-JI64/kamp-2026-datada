# 1. 데이터

## 1.1 데이터 구조

분석에는 자원 최적화 AI 데이터셋의 `okm_augumented_2021.csv`를 사용하였다. 가이드북에 따르면 공장 변압기 센서에서 수집한 전력 기록에 ERP 생산량과 기상·달력·비용 정보를 결합한 자료다. **한 행은 한 시간에 대응하며, 해당 시간 안의 15분 구간별 전력값 네 개를 포함한다.**

| 항목 | 내용 |
|---|---|
| 원본 규모 | 6,168행 × 18열 |
| 수록 기간 | 2021년 1월 1일~9월 14일, 총 257일 |
| 기록 구조 | 날짜별 24행, 각 행에 `15분·30분·45분·60분` 전력값과 `평균` 수록 |
| 시간·달력 변수 | 날짜, 시간, 요일(`day`), 일(`d`), 월(`m`) |
| 생산·기상 변수 | 생산량, 기온, 풍속, 습도, 강수량 |
| 기타 변수 | 전기요금(계절), 공장인원, 인건비 |

주요 시간 분석에는 1~8월 자료를 사용하였다. 이 기간의 5,832행에서 아래의 시간 오류 48행을 제외하여 **5,784행·241일**을 확보하였다. 9월 336행은 이후 주요 분석과 모델 평가에서 보류했으나 초기 탐색에는 포함되었으므로, 완전히 미관찰한 시험자료로 간주하지 않았다.

## 1.2 전력 목표와 변수 사용 기준

원본 `평균`은 네 전력값의 산술평균을 정수로 반올림한 값이다. 전체 6,168행에서 `평균 = floor((15분+30분+45분+60분)/4 + 0.5)`가 성립하였다. 본 분석은 이 **평균 전력**과 **같은 행의 네 전력값 중 최대**를 구분하였다. 가이드북의 15분 수요전력·피크 관리 맥락은 채택하되, CSV의 원단위와 정확한 계측 집계식은 현 자료에서 식별되지 않아 수치를 전력 기록값으로 제시하였다. kW·kWh나 실제 요금으로 환산하지 않았다.

`공장인원`은 비결측 6,151행 모두에서 다음 식과 소수점 저장 오차 수준으로 일치하였다.

`공장인원 = 생산량 ÷ (15분 + 30분 + 45분 + 60분)`

따라서 실제 근무 인원수로 해석하지 않았다. 같은 시점 전력이 계산에 포함되어 있어, 전력 예측에 사용하면 정답 정보가 유입될 수 있으므로 입력에서 제외하였다. 목표 시간의 전력 네 값 역시 해당 시간 평균을 예측하는 입력으로 사용하지 않았다.

기본 예측 모델에는 **과거 전력과 달력 정보**를 사용하였다. 이전 시간의 전력 기록이 예측 시점까지 관측 완료되어 이용 가능하다는 가정 아래 평가했으며, 실제 수집 지연은 현 자료에서 식별되지 않았다. 생산량은 계획·실적 구분과 사전 이용 가능 시점이 불분명하고, 기상값도 예측 당시 사용할 수 있었던 예보인지 확인되지 않았다. 따라서 목표 시간의 실제 생산량·기상을 미리 알고 있다고 가정하지 않았다. 과거 생산량·기상의 추가 활용은 별도 모델 비교에서 검토하였다.

**관련 Python 코드:** [EDA/scripts/data_overview.py](<D:/대회/제6회 K-인공지능 제조데이터 분석 경진대회/EDA/scripts/data_overview.py>)의 `main()`에서 이 절의 기록상 수치를 재현한다.

## 1.3 결측치 현황과 처리

원본 전체에서 결측은 **21셀**이며 풍속·강수량·공장인원에만 존재한다. 전력 네 값과 평균, 생산량에는 결측이 없다.

| 변수 | 결측 수 | 확인 내용 | 실제 처리 |
|---|---:|---|---|
| 풍속 | 3 | 6월 1일 01·02시, 7월 4일 20시 | 기술통계에서는 해당 변수의 결측만 제외하였다. 과거 기상을 추가한 모델 비교에서는 결측을 유지하고 HGB의 자체 결측 처리를 사용하였다. |
| 강수량 | 1 | 1월 24일 00시 | 풍속과 동일하게 처리하였다. 결측을 강수량 0으로 대체하지 않았다. |
| 공장인원 | 17 | 8월 28일 18시~29일 10시. 생산량과 전력 네 값이 모두 0으로, 비율식의 0/0에 해당 | 1.2의 계산 관계에 따라 변수 자체를 예측 입력에서 제외하였다. 이 변수의 결측 때문에 해당 행을 삭제하지 않았다. |

기초 상관분석에서는 비교하는 두 변수에 모두 값이 있는 행을 사용하였다. 기본 예측 모델은 과거 전력과 달력을 입력으로 사용하므로 원본 기상 결측을 채울 필요가 없었다.

다만 시작 구간이나 시간 오류 주변에서는 모델이 요구하는 과거 전력 기록이 부족했다. 필요한 입력을 모두 확보한 시점만 사용하여 정상 시간 5,784행 중 **5,520행을 모델링에 사용하였다.** 나머지 264행은 과거 입력 부족으로 제외한 것이며 원본 전력값이 결측이어서 제외한 것은 아니다.

## 1.4 시간 오류·극단값·0값의 처리

**시간 범위를 벗어난 명확한 오류는 분석에서 제외하고, 값이 크거나 0이라는 이유만으로 관측값을 삭제하지 않았다.**

| 구분 | 확인 결과 | 실제 처리와 이유 |
|---|---|---|
| 시간 범위 오류 | 7월 13일·15일 각 24행, 총 48행의 `시간`이 70~188로 기록됨 | 원본은 보존하고 시간순 분석에서 제외하였다. 실제 시각을 확인할 근거가 없어 행 순서나 중앙값으로 복원하지 않았다. 과거 값도 정확한 날짜·시간 차이로 연결해 오류 구간 양옆을 한 시간 간격으로 잘못 붙이지 않았다. |
| 생산량 극단값 | 1~8월 5,832행 중 533행이 1.5×IQR 기준 밖에 위치. 최댓값 9,830 | 오른쪽 꼬리가 긴 분포이며 큰 값 자체를 오류로 볼 근거가 없어 보존하였다. 로그 변환은 관계 탐색에서 비교했으며 원본값을 덮어쓰거나 일괄 변환하지 않았다. |
| 강수량 극단값 | 1~8월 비결측 5,831행 중 75.27%가 0. IQR이 0이어서 양수 강수량 1,442행 모두가 기준 밖으로 표시됨 | IQR 기준을 기계적으로 적용하면 모든 양수 강수 기록이 제거되므로 이상치 삭제 기준으로 사용하지 않았다. |
| 전력 0값 | 원본에서 전력 네 값이 모두 0인 연속 17행 | 결측과 구분해 유지하였다. 실제 정지·정전·계측 문제 중 원인은 식별되지 않아 임의로 보간하거나 삭제하지 않았다. |

IQR 기준은 `Q1−1.5×IQR` 미만 또는 `Q3+1.5×IQR` 초과다. 위 생산량·강수량 수치는 시간 오류 행도 포함한 1~8월 변수별 분포 점검 결과이며, 시간순 분석의 5,784행과 분모가 다르다. 높은 전력값 역시 피크 분석의 대상이므로 크기만을 이유로 제거하지 않았다.

## 1.5 데이터의 주요 특이점

### 날짜가 달라도 반복되는 하루 전력 기록

원본 전체의 완전히 동일한 중복 행은 0개였지만, 전력값만 비교하면 다른 날짜에 같은 하루 배열이 반복되었다. 1~8월 정상 241일에서 하루 96개 전력값이 만드는 서로 다른 배열은 **126개**였으며, **160일이 반복 그룹에 속했다.** 날짜·생산량·기상까지 같은 중복 행은 아니므로 반복 날짜를 일괄 삭제하지 않았다. 분석에서는 반복 배열의 가중치를 조정한 민감도를 확인하였고 모델은 시간순으로 평가하였다. 반복 원인이 실제 조업 패턴인지 자료 가공 과정인지는 식별되지 않았다.

### 생산량 0과 실제 비가동은 구분

원본 6,168행 중 생산량이 0인 행은 **2,657행**이며, 그중 **2,640행에는 양수의 평균 전력값**이 기록되어 있다. 따라서 생산량 0을 결측으로 바꾸거나 해당 행을 삭제하지 않았고, 실제 비가동 상태로도 단정하지 않았다.

가이드북은 생산량의 출처를 ERP 일자별 자료로 설명하지만, 정상 241일 중 181일에는 날짜 안에서 여러 생산값이 기록되어 있었다. 일자 자료를 시간별로 배정한 방식은 식별되지 않으므로 생산량은 CSV의 기록값으로 해석하였다. 시간별 기록의 합을 검증된 공식 일일 생산실적으로 간주하지 않았다.
