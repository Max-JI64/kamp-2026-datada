# 새 EDA 작업

현재 다시 구성하는 EDA의 작업 폴더다. 기존 EDA는 보존하고, 이후 코드와 산출물은 이 폴더에서 관리한다.

## 원고 구성 갱신 — 기존 2.3 제외

사용자가 전력값 예측을 우선하는 방향에서 2.3 제외와 후속 EDA 구성을 요청했다. 미확정 187 기준에 의존하는 기존 2.3을 새 원고 본문에서 제외하고 원문 전체를 `tables/peak_definition_comparison/withdrawn_section_2_3.md`에 보관했다. 2.1·2.2는 그대로 유지했으며, 본문과 보관 절을 합치면 수정 전 원문과 일치함을 확인했다. 기존 분석·결과표·이미지는 보존했다. 대체 절은 아직 작성하지 않았다. 다음 구성 후보는 날짜별 하루 패턴의 반복·수준 변화와 한 시간 평균 대비 15분 값의 변동이다. 계산·플롯은 범위를 정한 뒤 기존 결과를 우선 재사용한다.

| 폴더 | 내용 |
|---|---|
| `scripts` | 계산·시각화·검증 코드 |
| `tables` | 결과표, 입력 범위, 계산·검증 기록 |
| `figures` | 생성한 플롯과 시각 검수 기록 |

## 현재 작업

- 하루 패턴: `scripts/eda_daily_pattern.py`
- 생산량·날씨·전력 관계: `scripts/eda_variable_relations.py`
- 기존 피크 정의·군집 수 비교: `scripts/compare_peak_definitions.py`, `scripts/compare_fixed_cluster_counts.py`
- 전체 기간의 POT 진단: `scripts/analyze_pot_tail.py`, `scripts/plot_pot_tail.py`, `scripts/summarize_pot_tail.py`
- 새 2.3 날짜별 반복: `scripts/eda_daily_repetition.py`. 결과는 `tables/daily_repetition`, 그림은 `figures/daily_repetition`. 본문은 미작성.

## 새 2.3 분석 결과 — 본문 미작성

2.1의 평일 평균에서 보인 11→12시 하락·12→13시 상승이 실제 날짜에서도 나타나는지 시간 평균 전력으로 확인했다. 평일 147/171일, 주말 13/70일이었다. 평일 예외 24일 중 20일은 하루 생산량 기록이 모두 0이었고, 생산량이 양수인 기록이 있는 평일에서는 145/149일이 해당했다. 주말은 생산 여부를 나눠도 비율이 낮았다. 월별 집계와 반복된 96개 전력값 패턴당 한 번의 가중치로 보조 확인했다. 날짜별 히트맵·개별 선과 중앙값/분포·날짜별 짝지은 변화 산점도 세 개를 만들고 50% 접촉 시트로 확인했다. 해석·예외·종료 판단은 `tables/daily_repetition/interpretation.json`에 있다. 원본과 새 원고는 수정하지 않았으며 원고 해시가 실행 전후 동일함을 확인했다.

사용자가 히트맵의 가독성 문제를 지적하고 그림만으로 이해할 수 있는 선그래프와 월별 비교를 요청했다. `scripts/plot_daily_repetition_simple.py`에서 기존 표를 재사용해 전체 기간의 평일·주말 선그래프 `04_daily_pattern_simple.png`와 1~8월을 같은 축에서 비교하는 `05_monthly_daily_lines.png`를 만들었다. 날짜별 가는 선을 제거하고 평균·중앙값·분포 및 반복 일수를 표시했다. 월별 그림은 평일·주말 중앙값과 날짜 간 가운데 80% 범위다. 새 후보 두 개를 각각 50%로 확인했으며 원고는 미작성 상태다.

최신 수정: 사용자는 직관적인 플롯을 요구한 것이며 그림 안의 화살표·해석 문구나 날짜 전수 나열을 요구한 것이 아니라고 명확히 했다. 두 선그래프에서 화살표·해석 문구·결과 수치를 제거했다. 전체 기간 그림은 평균·중앙값과 P10~P90 음영만 표시한다. 월별 그림은 음영도 제거하고 평일·주말 중앙값 선 두 개만 표시한다. 같은 이름의 이미지를 실제 교체하고 각각 50%로 확인했다. 이전 날짜 전수 히트맵은 현재 수록 후보에서 제외한다. 해석과 반복 비율은 결과표에 보존하고 원고는 아직 작성하지 않았다.

월별 비교의 수록 가치를 다시 확인했다. 평일 08시의 6월/7월 중앙값은 171.5/187.5이며, 주말 10시의 1월/3월 중앙값 85.5/91.5와 2·7·8월 21~24의 차이는 전체 기간 그래프에서 가려진다. 월별 관측 차이를 남기되 선그래프 8패널 대신 `06_monthly_power_heatmap.png`의 평일·주말 두 패널, 각각 8개월×24시간 요약을 우선 후보로 제시했다. 중앙값 정의와 공통 색 범위를 유지했고 실제 384칸 완전성을 확인했다. 그림은 50%로 검수했으며 원고는 수정하지 않았다. 주말은 월당 8~10일이며 날짜 구성의 차이가 포함되므로 계절·날씨의 원인 효과로 표현하지 않는다. 근거와 판단은 `tables/daily_repetition/monthly_heatmap_manifest.json`에 있다.

사용자가 7·8월의 낮은 표시값과 중앙값 선택 이유를 질문해 원본에서 독립 검증했다. `scripts/verify_monthly_power_heatmap.py`에서 그림의 384개 중앙값과 날짜 수를 모두 대조했고 오차는 0이었다. 평일 08시의 7월 평균/중앙값은 185.05/187.5, 8월은 142.68/172.5다. 8월은 생산량 기록이 하루 모두 0인 평일 5일의 08시 평균 21이 포함된다. 이 날짜들을 임의로 제외하지 않는다. 200 이상의 시간 평균도 존재하며 7월 최고 208, 8월 최고 203이다. 중앙값은 전형적 수준의 요약이며 월별 산술평균을 대신하는 값이 아니다. 현재 이미지는 중앙값 버전을 그대로 보존했고 원고는 수정하지 않았다. 근거는 `tables/daily_repetition/independent_heatmap_verification.json`이다.

사용자가 평균 히트맵 생성을 요청해 `plot_monthly_power_heatmap.py --statistic mean`으로 `07_monthly_power_mean_heatmap.png`를 생성했다. 원자료에서 독립 계산한 384개 월×달력×시간 평균을 사용했다. 월별 표본 수로 가중해 다시 합쳤을 때 2.1의 48개 평일/주말×시간 평균과 모두 일치함을 확인했고 실제 CPython 3.13 종료 0, 글꼴 경고 없음, 50% 시각 검수 완료다. 낮은 전력 날짜와 생산량 0 날짜도 포함했다. 그림은 평균 버전을 우선 후보로 하고 중앙값 버전은 보조로 보존한다. 절 순서는 2.1 하루 패턴 → 2.2 월별 변화 → 2.3 생산량·날씨 관계가 자연스럽다고 제안했다. 사용자 요청에 따라 본문과 현재 절 번호는 아직 수정하지 않았다.

현재 POT 탐색은 **1~8월 정상 시간 5,784행 전체**를 사용한다. 이전 시간 분할을 사용한 `tables/peak_definition_comparison/pot_tail` 결과는 현재 EDA의 기준 선정 근거에서 제외한다. 현재 결과는 `tables/peak_definition_comparison/pot_tail_eda_full`, 그림은 `figures/peak_definition_comparison/pot_tail_eda_full`에 있다.

POT 실행 순서는 `analyze_pot_tail.py scan` → `analyze_pot_tail.py bootstrap` → `summarize_pot_tail.py` → `plot_pot_tail.py`다. 정규 CPython 3.13을 사용하며 Windows 실행 경로는 상위 AGENTS.md를 따른다.

현재 원고 본문에는 이번 POT 결과를 반영하지 않았다. 폴더 경로 변경 후 전체 EDA의 모든 과거 계산을 재실행했다는 뜻도 아니다. 활성 POT 코드의 결과 및 검증 상태는 해당 JSON에 기록한다.

## 전력 수준과 급상승 재검토

사용자의 60→90, 100→140 예시에서 출발해 전력 수준과 인접 15분 구간의 상승폭을 분리했다. `scripts/review_power_jumps.py` → `scripts/plot_power_jumps.py` 순서로 실행한다. 결과와 선정 규칙은 `tables/power_jumps_review/interpretation.md`, 그림은 `figures/power_jumps_review`에 있다. 수정 Z 참고 규칙에서 정수 상승폭 21 이상은 1,485구간이지만 바로 다음 구간에서 21 이상 내려오는 경우는 12개다. 반복 시각과 하루 패턴 가중치에 민감하므로 급상승을 이상 상황이나 공식 피크로 확정하지 않았다. 기존 187은 그림의 미확정 비교선이며 최종 기준이나 원고를 변경하지 않았다.

## POT 실행 결과

전체 기간의 145~205 기준을 진단하고 60회 주별 재표본 적합 3,240개와 핵심 표 122개를 검증했다. 플롯 5개는 50% 접촉 시트로 확인했다. 시간별 초과값의 176~194에서 모수가 비교적 일정하지만, 사건 최대값은 연결 간격·추정법에 더 민감하다. 단일 피크 경계는 확정하지 않았다. 이전 근거·이번 결과·판단·종료 근거는 `tables/peak_definition_comparison/pot_tail_eda_full/interpretation.json`에 기록했다.
