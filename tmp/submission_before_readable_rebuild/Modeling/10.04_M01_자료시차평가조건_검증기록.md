# M01 자료·시차·평가 조건 검증

2026-10-04. 사용자 요청으로 M01을 실행했다. 정규 CPython 3.13.1의 준비 코드와 별도 검증 코드는 모두 종료 코드 0이었다. 원본을 보존했으며 모델 학습·성능 평가·피크 기준 산정은 수행하지 않았다.

## 이전 근거와 이번 질문

[A04](../Analysis/10.03_A04_다음시간최대전력과선행정보_분석기록.md)의 마지막 값과 다음 최대값 관계 +0.409는 입력 비교의 근거지만 예측 성과는 아니다. [A05](../Analysis/10.03_A05_EDA_Analysis_후속질문점검.md)는 전날·전주 기준 비교와 새 모델의 실제 시차·분할 검증을 미완료 질문으로 남겼다. 따라서 이번 질문은 **동일한 정보 시점과 표본으로 단순 기준·기본 모델·마지막 값 추가를 비교할 수 있는가**다.

실행 전 [조건 파일](config/m01_contract.json)에 목표·자료 범위·시차·분할·입력 목록·결측 정책·초기 모델 후보를 기록했다. 원본 해시와 알려진 정상 자료 수, 정확한 시차 연결 수가 맞고, 목표와 과거 입력을 원본으로 독립 대조할 수 있어야 M02 준비가 완료된 것으로 판단했다. 반복 배열 겹침은 삭제 기준으로 삼지 않고 이후 성능의 해석 조건으로 기록했다.

## 확정한 정의와 입력 경계

- 자료: 1~8월 5,832행 중 시각 오류 48행 제외, 정상 241일·5,784시간. 9월 336행은 분석 표본·시차·학습에 편입하지 않았다. 파일 해시·전체 규모 확인은 원본 전체를 대상으로 했다.
- 주 목표: 목표 시간 네 15분 값의 최댓값. 보조 목표와 과거 평균 입력: 네 값의 반올림 전 산술평균. 원본 반올림 평균은 보조 진단 열에만 보관했다.
- 시점: 관측을 마친 `t−1`시간의 기록으로 `t`를 예측한다. 기록 보고 지연 없이 이용 가능하다는 가정은 현재 자료에서 검증할 수 없으며 명시적으로 남긴다.
- 달력: 목표 시간의 시간대 사인·코사인, 월, 평일/주말, 요일 더미. 과거 입력: 직전 생산량·0 여부, 1·2시간 전 평균 및 최대값. 마지막 값·24·168시간 시차·직전 날씨는 비교 묶음으로 분리했다.
- 입력 목록은 [변수표](tables/m01/feature_dictionary.csv)와 `feature_columns()`로 지정한다. 저장 자료에는 목표 생산량·생산 전환·하루 배열 등 진단 열도 있지만 입력 목록에 포함하지 않는다. 목표 시간의 실제 날씨·공장인원·하루 최대 시간도 입력으로 사용하지 않는다.
- 초기 모델 후보: Ridge의 alpha 1·10, HGB의 최대 잎 7·15. HGB는 학습률 0.05, 150회, 최소 잎 표본 20, L2 1, 조기 종료 비활성, 시드 42로 비교한다. Ridge 스케일링과 날씨 결측 처리는 학습 안에서만 적합한다. 패키지 가용성은 확인했으며 모델 적합은 아직 실행하지 않았다.
- 분할별 한 번 학습한 후 평가 중 모델을 재학습하지 않는다. 매시간 관측을 마친 입력은 갱신한다. 초기 비교에서 예측값을 자동으로 0에 절단하지 않고, 음수 예측이 나오면 오류진단으로 확인한다.

`A`는 기본 입력, `B`는 A에 마지막 값 추가, `C_A`·`C_B`는 각 구성에 전날·전주 전력 추가다. 날씨 `D`의 변수표는 현재 C_B에 날씨를 붙인 후보 목록이며, 실제 실행에서는 개발에서 선택한 부모 입력 구성을 먼저 확정하고 조건 버전을 갱신한다. D를 선택 결과와 무관하게 강제 실행하지 않는다.

## 정확한 시차와 공통 표본

| 연결 조건 | 가용 시간 | 제외 시간 | 제외 이유 |
|---|---:|---:|---|
| 1시간 전 | 5,781 | 3 | 범위 시작 1, 시각 오류 날짜 뒤 2 |
| 2시간 전 | 5,778 | 6 | 범위 시작 2, 시각 오류 날짜 뒤 4 |
| 24시간 전 | 5,712 | 72 | 범위 시작 24, 시각 오류 날짜의 영향 48 |
| 168시간 전 | 5,568 | 216 | 범위 시작 168, 시각 오류 날짜의 영향 48 |

제외 수는 정상 5,784시간 기준이며, 시차별 누락이 겹쳐 합산하지 않는다. 날짜·시간의 정확한 조회를 사용했으며 누락 날짜를 건너뛴 이전 행을 1시간 전으로 취급하지 않았다. [시차 가용성](tables/m01/lag_coverage.csv)과 [누락 원인·요청 시각](tables/m01/unavailable_lags.csv)에 전수 기록했다.

주 비교는 common을 학습·평가 양쪽에 동일하게 적용한다. 마지막 값 효과와 전날·전주 입력의 효과를 표본 변경과 섞지 않기 위한 선택이다. 더 많은 시간에 적용 가능한 A/B는 core로 보조 비교하며, 두 표본의 점수를 같은 비교로 합치지 않는다.

과거 전력·생산 시차가 없는 행은 해당 모델 비교에서 제외하며 보간하지 않는다. 날씨는 직전 풍속 3시간·강수량 1시간이 결측이다. D 실행 시 학습 중앙값과 결측 표시를 사용해 동일 평가 행을 유지하며, 학습에서 전부 결측인 변수는 제외 이유를 남긴다. 미래 기상으로 보간하지 않는다.

직전·전날·전주 단순 기준의 보조 가용성에는 각각 1, 24→1, 168→24→1의 순서를 고정했다. 각 기준은 자신에게 필요한 시차가 있으면 사용할 수 있다. 예를 들어 직전 입력이 없어 A/B가 예측할 수 없는 시간에도 전주 기준은 해당 시차가 있으면 가능하다. 어느 허용 시차도 없을 때만 예측을 보류한다. 이 대체 규칙의 점수는 common 비교와 별도로 보고한다.

7~8월의 직전 단순 기준은 1,438/1,440시간 가능하고 2시간 보류한다. 전날 기준은 전날 1,392시간·직전 대체 46시간·보류 2시간이다. 전주 기준은 전주 1,392시간·전날 대체 48시간으로 1,440시간 가능하다. 이는 [가용성](tables/m01/baseline_fallback_coverage.csv)이며 정확도 결과는 아니다.

## 반복 배열 겹침과 해석 변경

원자료 정상 241일의 96칸 배열은 126종이며 160일이 반복 그룹에 속한다. common 학습에 포함된 목표 날짜의 배열과 평가 배열을 비교했다.

| 평가 | 평가 일수 | 학습과 같은 배열인 날짜 | 해당 시간 | 새로운 배열인 시간 |
|---|---:|---:|---:|---:|
| 4월 | 30 | 0 | 0 | 720 |
| 5월 | 31 | 17 | 408 | 336 |
| 6월 | 30 | 26 | 624 | 96 |
| 7~8월 | 56 | 0 | 0 | 1,344 |

core는 6월 겹침이 28일·672시간으로 더 많고 새로운 배열은 2일·48시간이다. common은 초기 7일을 학습에서 제외해 일부 배열이 학습 표본에 없어 두 표본의 겹침 수가 다르다. [배열 겹침](tables/m01/profile_overlap.csv)에 두 경우를 구분했다.

**확인된 사실:** 개발 분할에서 평가 행을 구성할 수 있지만 5·6월에는 동일 배열이 학습에 많이 등장한다. **유지할 판단:** 시간순 개발 분할과 모든 관측값을 유지한다. **보완할 해석:** 이후 모델 비교는 전체·월별 결과에 겹침/새 배열 결과와 평가 안의 반복 배열 비중을 낮춘 보조 결과를 병기한다. 특히 6월 common의 새 배열은 4일뿐이므로 그 결과를 안정성의 단독 근거로 삼지 않는다.

가중치는 평가 표본의 동일 배열에 속한 날짜 수의 역수이며 사후 보조 평가에만 쓴다. 학습에 자동으로 적용하지 않는다. 하루 배열과 실제 최대 시간은 결과 확인 후의 진단이다. 후반기에서 직접 같은 배열이 없다는 사실도 자료 생성의 독립성이나 새 시험을 입증하지 않는다. 7~8월은 이미 관찰한 내부 후반기 평가다.

## 다음 비교 조건과 종료 판단

M02의 질문은 **동일한 common 표본에서 직전·전날·전주 기준과 Ridge·HGB 중 어떤 방법이 개발 기간의 최대전력을 잘 예측하며, 어디에서 실패하는가**다. A 입력으로 모델 계열·설정을 비교하고, 개발 3개월의 합친 MAE를 주 지표로 사용한다. 월별 MAE·RMSE, 일별 최대 시간의 과소·과대예측과 배열 겹침별 결과를 함께 남긴다. 최소 MAE의 1% 안은 수치상 비슷한 후보로 보고 단순한 구성을 우선한다. 이 1%는 비교 규칙이며 경제적 최적값이나 필살기 개선 기준은 아니다.

M03의 A/B 비교는 모델 설정을 같게 유지한다. 입력 효과와 튜닝 효과를 섞지 않는다. 최종 선택의 전체 오차·과대예측 허용 범위는 개발 근거를 본 뒤 M05 전 별도 고정하며 아직 결정되지 않았다. 설정 변경은 다음 비교 실행 전에 이유와 새 버전을 기록한다. 현재 후보나 후속 순서를 결과와 무관하게 강제하지 않는다.

**M01은 완료다.** 원본·시각·표본·목표·입력 경계와 사후 진단 가중치를 검증했고 M02에서 사용할 조건을 저장했다. 실제 모델 우열, 마지막 값의 성능 기여, 오류 집중조건은 이번 작업으로 답하지 않았으며 M02·M03·M04의 실행 질문으로 남긴다. 이번 승인 범위인 M01에서 종료하고 학습은 아직 시작하지 않았다.
