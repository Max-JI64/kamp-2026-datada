## 1. 문서의 범위와 확인 기준

이 문서는 CSV 전체 6,168행의 열 구성, 값 분포, 결측, 중복, 날짜 관계와 파생식 검증 결과를 정리한다. 원본 데이터는 수정하지 않았다.

- 변수의 업무상 의미는 제공된 [데이터 개요](../data/origin/개요.md)를 참고했다.
- 예측 과제의 방향은 로컬 [과제공개 문서](../대회개요/과제공개.md)의 자원 최적화 과제를 참고했다.
- 행 수, 범위, 결측 수, 계산 관계는 정규 CPython 3.13과 pandas·NumPy로 실제 CSV에서 확인했다.
- 문서에 없는 단위, 관측 장소, 증강 방식, 업무상 정의는 확정하지 않았다. 아래에서 ‘추정’ 또는 ‘미확인’으로 구분한다.
- 외부 가이드북, 최신 요금표, 공식 사이트를 추가 검증한 문서는 아니다.

**핵심 결과:** `평균`을 예측 대상으로 삼으면 정답은 6,168개 모두 존재한다. 다만 시간값 오류 48행, 결측값 21개, `공장인원`의 정답 누출 가능성을 고려해야 한다.

## 5. 평균의 계산 방식과 분포

전체 6,168행에서 다음 식이 성립한다.

```text
평균 = floor((15분 + 30분 + 45분 + 60분) / 4 + 0.5)
```

양수 기준으로 소수 부분이 0.5 이상이면 올리는 정수 반올림이다. Python 기본 `round()`의 0.5 처리와는 일부 결과가 다르다.

첫 행의 예:

```text
15분=62, 30분=61, 45분=61, 60분=61
산술평균 = 61.25
저장된 평균 = 61
```

| 평균 열의 분포 지표 | 값 |
|---|---:|
| 최솟값 | 0 |
| 25백분위수 | 23 |
| 중앙값 | 104 |
| 산술평균 | 약 93.424 |
| 75백분위수 | 144 |
| 95백분위수 | 177 |
| 99백분위수 | 189 |
| 최댓값 | 208 |

최댓값 208은 2021-07-28 11시와 2021-07-30 11시에 나타난다.

`평균`은 시간 안의 최대값이 아니다. 시간 평균이 높지 않아도 특정 15분 값은 높을 수 있으므로, 피크 분석에서는 네 구간의 최댓값을 별도로 살펴봐야 한다. 위 백분위수는 전체 파일의 기술통계이며, 모델의 경보 임계값으로 확정한 값이 아니다.

## 6. 공장인원 계산 관계와 정답 누출

결측이 아닌 6,151행 전체에서 아래 관계가 소수점 저장 오차 수준으로 일치한다. 최대 절대 오차는 약 `4.94 × 10⁻⁹`다.

```text
공장인원 = 생산량 / (15분 + 30분 + 45분 + 60분)
```

마지막 행의 예:

```text
생산량 = 405
전력값 합계 = 117 + 119 + 112 + 91 = 439
405 / 439 = 0.922551253...
공장인원 = 0.922551253
```

이 관계로부터 확인되는 사항은 다음과 같다.

- `공장인원`을 실제 근무자 수로 해석할 근거가 부족하다.
- 데이터상으로는 생산량을 같은 행의 전력값 합계로 나눈 비율이다. 공식 생성 의도나 변수명 오류 여부까지 확인한 것은 아니다.
- 생산량과 이 비율이 양수이면 전력 합계를 역산할 수 있다.
- **같은 행의 평균 예측에 공장인원을 입력하면 정답 정보가 간접적으로 제공된다.**
- 과거 시점의 값으로 사용하더라도 생성 방식과 실제 이용 가능 시점을 확인해야 한다.

공장인원이 결측인 17행은 생산량과 전력값 4개가 모두 0인 구간과 정확히 일치한다. 이는 위 비율식의 `0/0`이 정의되지 않는 상황과 부합한다.

## 7. 시간 오류·결측·0값 진단

| 항목 | 확인 내용 | 유의점 |
|---|---|---|
| 시간 범위 오류 | **2021-07-13의 24행, 2021-07-15의 24행**, 총 48행 | 시간에 70~188이 기록됨 |
| 날짜·시간 중복 | 첫 기록 제외 중복 5행 | 전체 행 중복은 아니므로 단순 삭제 금지 |
| 풍속 결측 | 2021-06-01 01시·02시, 2021-07-04 20시 | 총 3개 |
| 강수량 결측 | 2021-01-24 00시 | 총 1개 |
| 공장인원 결측 | 2021-08-28 18시~2021-08-29 10시 | 연속 17행 |
| 평균 전력 0 | 위와 같은 연속 17행 | 실제 정지·정전·계측 누락 중 원인 미확인 |
| 생산량 0 | **2,657행**, 약 43.1% | 0을 결측으로 취급하지 않음 |
| 생산량 0, 평균 전력 양수 | **2,640행** | 비생산 구간에도 전력값이 기록됨 |

시간 오류가 있는 날에도 행은 24개씩 있다. 그러나 행 순서만으로 0~23시를 자동 부여하는 것은 검증되지 않은 복원이다. 원본 시간의 근거를 먼저 확인해야 한다.

잘못된 값에 단순히 `날짜 + 시간(hour)`를 적용하면 70시간 등이 며칠 뒤 시각으로 넘어가 가짜 중복·누락이 생긴다. 시간 범위를 먼저 검사해야 한다.

0값과 결측은 다르다. 생산량 0이지만 전력이 양수인 구간을 대기전력이라고 단정할 수는 없으며, 실제 가동 상태를 확인할 별도 자료가 필요하다.

## 10. 예측 입력의 이용 가능 시점

로컬 과제 문서의 요구는 ‘향후 지정된 시간구간의 전력사용량’ 예측이다. 예측 대상 시간에 해당하는 값이 파일에 있다는 사실과, 예측 시점에 미리 알 수 있다는 사실을 구분해야 한다.

| 변수 종류 | 사용 판단 |
|---|---|
| 예측할 날짜·시간·요일·월 | 미래에도 미리 알 수 있으므로 사용 가능 |
| 확정된 요금·근무 계수 | 해당 시점에 사전 확정되는 값인지 확인 후 사용 |
| 과거 전력값·과거 평균 | 관측이 완료된 과거 값이면 사용 가능 |
| 예측 대상 구간의 전력 4개 값 | 해당 구간 평균의 예측 입력으로 사용하면 누출 |
| 예측 대상 구간의 공장인원 | 같은 구간 전력에서 계산된 값이므로 누출 위험 |
| 미래 생산량 | 계획 생산량인지 실제 생산 실적인지 구분 필요 |
| 미래 기상값 | 미래 관측 실황과 예측 당시 이용 가능한 예보를 구분 |

설비 ID, 제품 종류, 교대조, 개별 설비 가동 상태가 없으므로 이 파일만으로 특정 설비의 동시 가동이나 제품 전환이 피크의 원인이라고 직접 확인할 수 없다. 생산량·시간·기상 조건과 전력의 관계를 분석하는 것과 인과관계를 입증하는 것은 구분해야 한다.

## 11. 모델링 전 확인할 사항

1. 전력값의 단위, 구간 시작·종료 시각과 계측 방식을 확인한다.
2. 시간 오류 48행의 원본 근거를 확인하고 복원 또는 제외 기준을 기록한다.
3. 공장인원과 인건비의 공식 정의·생성식을 확인한다.
4. 생산량이 계획인지 실적인지, 기상값이 어느 지역의 어떤 집계값인지 확인한다.
5. 예측 시작 시점, 예측할 미래 구간, 목표값을 명시한다.
6. 같은 시점의 전력 구성요소와 공장인원을 입력에 넣어 정답을 누출하지 않는다.
7. 시간 순서에 따른 학습·검증·시험 분할을 설계하고, 결측 처리와 임계값 산정은 학습 구간을 기준으로 수행한다.
8. 전력 0인 연속 17행의 원인을 확인한다. 원인이 불명확하면 포함·제외에 따른 결과 차이를 구분해 보고한다.

이 문서는 데이터 이해와 진단을 위한 기록이다. 시간값 복원, 결측 대체, 이상치 제거, 학습 데이터 분할과 모델 학습은 수행하지 않았다.
