## 4. 가이드북이 설명하는 가공 단계와 예측 목표

| 단계 | 가이드북 설명 | 자료 경계 |
|---|---|---|
| 1차 | `날짜`, `시간`, 전력 4개, `평균`, `생산량`의 8열을 변압기 센서와 ERP에서 구성. PDF 11쪽 | 원본 센서 기록·ERP 원본은 현재 CSV에 별도로 없다. |
| 2차 | 기상 4열과 전기요금, 달력 `day`·`d`·`m`, 인력·인건비 관련 열을 추가. 가이드북은 RNN용 추가 기상·요금과 RF/최적화용 달력·비용 정보를 설명. PDF 11~12쪽 | 어떤 열·행이 관측인지 합성인지, 원본 파일명의 `augumented`가 가리키는 증강 절차는 기술하지 않는다. |
| 3차 | 15분 전력 열을 골라 1주일=168시간의 과거값을 `t-1`~`t-168` 열로 만든 RNN 입력. PDF 12, 40~44쪽 | 이는 가이드북의 **파생 학습 파일**이며, 제공된 18열 원본 CSV와 다른 자료다. |

가이드북은 1차 자료를 변압기 센서 정보의 비식별화·품질 전처리 결과로 설명한다(PDF 10쪽). 이후 원본 전력 자료에 ERP 생산량을 결합하고, 2차 단계에서 기상·요금·달력·비용 관련 정보를 덧붙인다는 흐름이다. 또한 혼합된 학습 통합 데이터에서 빈 값을 0으로 바꾸고 상관관계가 낮은 변수를 제거하는 실습을 설명한다(PDF 10~11쪽). 어떤 행에 어떤 비식별화·대체·증강이 적용됐는지의 기록은 제시하지 않는다.

- **RNN 실습:** `15분` 전력 하나만 남긴 뒤 168개 과거 시간값에서 다음 1시간의 같은 위치 전력값을 예측한다. 6,168행 중 첫 169행을 제외한 5,999개 학습 후보를 만들고, 마지막 336시간(2021-09-01~09-14)을 평가 구간으로 둔다. 가이드북은 학습 5,663건이라고 적는다. PDF 41~47쪽.
- **RNN용 휴일:** `Weekend`와 2021년 지정 공휴일 `Vacation`을 추가하지만, 실제 168시간 창 생성 코드에서는 `15분` 열만 선택한다. 따라서 제시된 RNN 코드에 휴일값이 입력된다고 볼 수 없다. PDF 38~42쪽.
- **RF 실습:** 한 행의 전력 4개를 시간순 15분 관측으로 펼쳐 24,672개 연속값을 만들고, 입력의 다음 전력값을 목표로 둔다. 마지막 입력/첫 목표를 제거하므로 실제 학습 쌍은 코드상 24,671개다. 비용 관련 열은 별도 배열로 분리하고, 70:30 무작위 분할을 쓴다. PDF 56~59쪽.
- **최적화 예시:** RF 예측값, 계절 요금, 인건비·인력·생산량을 이용해 낮/밤 및 인력 배치를 정하는 예시를 제시한다. 생산량 양수인 사례를 사용하고 인원 상한 75 등의 제약을 둔다. 이는 가이드북의 예시 계산이며, 실제 인력 숫자·요금 단위·현장 실행 가능성의 검증 자료는 아니다. PDF 61~65쪽.
- 가이드북의 목표는 주로 `15분` 구간 값 또는 다음 15분 값이다. 현재 대회의 ‘향후 지정 시간구간 전력사용량’에 그대로 대응하는 목표·입력·예측 시작 시점은 별도 정의가 필요하다. 대회 과제는 [로컬 과제공개 문서](../../대회개요/과제공개.md)를 따른다.

| 가이드북 품질 지수 | 완전성 100%, 유일성 99.69%, 유효성·일관성·정확성 100%, 무결성 66.67%, 종합 약 96.63~96.64% 제시. PDF 83쪽 | 결측 0 대체 이후의 자체 지표·기준이며, 시간 오류·현재 키 중복률과 맞지 않는다. 현재 파일의 종합 품질 보증값으로 인용하지 않는다. |

가이드북은 결측률 30% 이상 열을 삭제하는 일반 규칙도 제시하지만, 현재 파일에는 이에 해당하는 열이 없다고 적는다(PDF 15, 78쪽). 30%는 이 데이터의 오류 근거가 아니므로 결측 원인을 확인하지 않은 삭제나 대체를 뜻하지 않는다.

## 6. 현재 CSV와 불일치하거나 여전히 미해결인 사항

1. **공장 인력 변수:** PDF 9쪽 표는 `공장직원`과 `공장이 보유한 생산력`, 11쪽은 직원 수라고 설명하지만 CSV 열은 `공장인원`이다. 현재 6,151개 비결측행의 값은 `생산량 / (15분+30분+45분+60분)`과 최대 절대오차 약 `4.94×10⁻⁹`로 일치한다. 공식 생성 의도는 가이드북에도 설명되지 않는다. 물리적 직원 수 또는 사전 이용 가능한 입력으로 쓰면 안 된다.
2. **원시 시각 대체:** PDF 33~34쪽은 원본 `날짜`·`시간` 열을 검증해 고치는 대신 2021-01-01 00:00부터 시간당 연속 `date_range`를 행 순서에 부여하고 원본 두 열을 버린다. CSV에는 실제로 유효하지 않은 시간값 48행과 날짜·시간 중복 5행이 있다. 행 순서가 원시 계측 시간과 정확히 같다는 독립 근거가 없으므로 이 코드는 시각 복원의 증거가 아니다.
3. **가이드북 기술통계:** PDF 10쪽 표는 `기온` 최솟값을 0, `풍속`·`강수량`·`공장직원` 개수를 각 6,168로 적는다. 현재 CSV의 기온 최솟값은 **-12.0**, 이 셋의 비결측 수는 각각 **6,165·6,167·6,151**이다. 어떤 전처리 단계의 통계인지 표에 표시되지 않아 원본 CSV의 확인값으로 옮기지 않는다.
4. **모델 평가 해석:** PDF 46쪽의 `MinMaxScaler.fit_transform`은 평가 구간 분리 전 전체 창 자료에 적용된다. PDF 58쪽 RF는 15분 연속값을 무작위로 분리한다. PDF 58쪽 입력 생성 코드에는 첫 행의 비전력 설명변수만 반복 사용하는 구문도 있다. 따라서 가이드북 예시 성능과 주말 오차 해석(PDF 53쪽)을 현재 프로젝트의 미래 예측 성능으로 전용할 수 없다. 특히 비용 배열과 입력 배열의 행 정렬은 별도 재검증이 필요하다.
5. **남은 데이터 정의:** 전력 단위·계측 집계식·시간 구간 표기, ERP 일자별 생산량의 시간별 대응·계획/실적, 기상 관측지·집계 방식, 전기요금 적용 규칙, 원본 관측/증강 구분, 전력 0이 지속된 17행의 실제 현장 상태는 이 가이드북에서도 확인되지 않는다. 가이드북의 일반 공정 설명만으로 개별 설비·생산조건의 피크 원인을 확정할 수 없다.

## 7. 기존 문서에서 갱신할 판단과 사용 경계

- 기존 [데이터 변수표](./데이터_변수표.md)와 [014 정의 점검](../../EDA/jsw/reports/09.23_014_definition_audit.md)의 ‘가이드북 미확보’ 상태는 이제 **가이드북 확보·본문 확인**으로 갱신할 수 있다. 이 문서는 기존 분석 결과를 다시 계산하거나 덮어쓰지 않는다.
- 새로 확인한 것은 4개 전력 열의 **시간 안 구간 정의**, 변압기·ERP·기상청·한국전력이라는 **가이드북상 출처**, 선박 엔진용 볼트·너트 공정이라는 **사례 맥락**, 그리고 가이드북이 제시한 가공·예측 절차다.
- 여전히 확정하지 못한 항목은 6절 5번에 남겼다. 후속 분석에서는 목표값과 예측 시작 시점에 맞춰 **그 시점에 실제로 이용 가능한 입력만** 고르고, `공장인원`의 같은 행 전력 누출과 원시 시각 오류를 먼저 처리해야 한다. 가이드북의 일괄 결측 0 대체·연속 시각 대체·무작위 평가 분할을 그대로 재사용하지 않는다.
