## 4.1 삽입 본문: 입력 데이터 구성과 이용 시점

모델은 직전 시간의 관측을 마친 시점에 다음 한 시간의 네 전력값 중 최대값을 예측한다. 목표 시간의 시간대·요일은 미리 알 수 있는 달력 정보로 사용하고, 전력·생산량·날씨는 관측을 마친 과거 기록에서만 구성한다. 목표 시간의 실제 전력·생산량·날씨와 미래 상태 지속 길이는 예측 입력에 넣지 않는다.

| 입력 정보 | 기본 HGB B0 | 보완 HGB B1 |
|---|---|---|
| 달력 | 시간대 사인·코사인, 월, 평일/주말, 요일 더미 11개 | B0와 동일 |
| 과거 전력 | 1·2시간 전 평균·최대, 직전 마지막 15분 값 5개 | B0에 과거 6시간 중앙값·IQR·범위·기울기, 직전 평균 변화, 마지막값과 평균의 차이, 시간 내부 범위 7개 추가 |
| 과거 생산량 | 직전 생산량, 직전 생산량 0 여부 2개 | 직전 생산량 변화 1개 추가 |
| 추적 상태 | 없음 | 과거 상태 경과시간·시작 경계 미관측 표시·방향 3개 |
| 분류 가용 표시 | 없음 | 이전 자료의 상승·하락 분류 학습 가능 여부 2개 |
| 합계 | 18개 | 31개 |

날씨 비교에서는 두 구성에 직전 시간의 기온·풍속·습도·강수량 4개만 추가했다. 학습 자료에서 결측이 확인되면 결측 표시도 추가한다. 시간 공백을 건너뛴 이전 행을 한 시간 전으로 취급하지 않고, 정확한 t−1 시각의 기록을 조회했다. 과거 기록을 관측 직후 이용할 수 있다는 가정은 실제 현장 적용 조건이다.

## 4.3 삽입 본문: 날씨의 추가 예측 가치와 입력 선택

날씨와 전력의 조건부 관계가 약하다는 결과만으로 날씨의 예측 가치를 배제할 수는 없다. 따라서 같은 HGB 설정·학습 행·평가 시각에서 과거 날씨 포함 여부를 비교했다. 2월부터 평가 월 이전까지의 자료로 학습하고 4·5·6월을 순차 평가했으며, 모든 구성은 공통 2,182시간을 사용했다. 지속 정답의 확인 시점을 맞추는 기존 B0·B1 조건을 유지했으므로, 이전 M03의 2,184시간 비교와는 분모가 다르다. 튜닝이나 평가 기록 삭제 없이 입력만 추가해 다시 학습했다.

| 개발 기간 4~6월 | 날씨 제외 MAE | 날씨 포함 MAE | 날씨 포함 시 변화 |
|---|---:|---:|---:|
| B0 전체 2,182시간 | 6.267 | 6.716 | 7.16% 증가 |
| B1 전체 2,182시간 | 6.392 | 6.692 | 4.69% 증가 |
| B0 일별 최대 시간 | 9.459 | 10.181 | 7.63% 증가 |
| B1 일별 최대 시간 | 9.844 | 9.915 | 0.72% 증가 |

일별 최대 시간은 완전한 예측 24시간이 있는 90일에서 평가했다. 최대값 동률은 날짜 안에서 가중치를 나눠 날짜마다 같은 비중을 부여했다. 최대 시각의 행 수는 136개다.

두 모델 모두 4·5·6월 각각의 전체 MAE가 증가했다. B0의 일별 평균 절대오차는 평가 91일 중 67일, B1은 64일에서 커졌다. 따라서 현재 설정에서는 날씨를 추가할 때의 이득이 특정 월의 전체 결과에 가려진 경우도 확인되지 않았다. 사전에 정한 전체 MAE 1% 이상 감소, 일별 최대 MAE 악화 1% 이하, 세 달 중 두 달 이상 전체 MAE 비악화 기준도 두 모델 모두 충족하지 못했다.

후반기에는 예외가 있었다. 6월 말에 고정한 모델로 7~8월 공통 1,344시간을 평가하면, 날씨 포함 B0의 전체 MAE는 6.335→6.409로 증가했지만 B1은 7.994→7.854로 감소했다. 다만 B1은 모든 시간에 사용하는 모델이 아니라 상승 경고 때만 적용하는 보완 모델이다.

| 7~8월의 동일 경고 7시간 | 날씨 제외 B1 | 날씨 포함 B1 |
|---|---:|---:|
| MAE | 13.981 | 13.092 |

경고 7시간의 B1 오차는 6.36% 줄었다. 이 효과를 분리하기 위해 B0는 그대로 두고 경고 때의 B1에만 날씨를 넣은 예측도 대조했다. 전체 MAE는 6.3172→6.3126으로 0.073% 감소했고 일별 최대 시간 MAE는 12.574→12.510으로 0.51% 감소했다. 그러나 같은 구성의 개발 기간 경고 12시간에서는 MAE가 8.661→9.308로 7.47% 증가했다. 이미 관찰한 후반기의 작은 이득만으로 날씨를 채택하거나 독립 검증 성과로 제시하지 않는다.

이 결과는 **현재 HGB 입력 구성과 고정 설정에서 날씨를 제외한 기존 구성을 유지할 근거**다. 날씨가 전력과 무관하거나 다른 모델·시차·설정에서도 불필요하다는 뜻은 아니다. 특히 보완 B1의 후반기 일부 조건에서는 이득이 있었으므로, 결론의 범위를 이번 전체·최대 시간 목표와 개발 비교 조건으로 제한한다.

## 4.12 삽입 본문: 보완 모델의 적용 범위와 기여

B1의 전체 시간 평균 기여와 실제 보완 시점의 기여는 구분해야 한다. 7~8월 공통 1,344시간 중 B1을 선택한 시간은 기존 상승 경고가 발생한 7시간이다. 따라서 B1을 모든 시간에 적용한 결과나 전체 시간의 변수 순위를 곧바로 현재 결합 예측의 성과로 해석하지 않는다.

경고 7시간에서 B1의 평균 절대 SHAP 상위 입력은 직전 마지막 전력값 35.79, 시간대 코사인 30.52, 직전 마지막값과 평균의 차이 5.69, 직전 평균 변화 4.78이었다. 전체 시간에서는 직전 마지막값과 시간대 코사인 다음으로 상태 경과시간의 순위가 높았지만, 경고 시점에는 시간 내부 차이와 직전 변화가 더 큰 기여를 보였다. 이는 보완 모델이 최근 전력의 수준뿐 아니라 변화 형태도 사용했다는 설명이다. 그 입력을 추가한 것만으로 오차가 얼마나 줄었는지를 개별적으로 식별한 제거 실험은 아니다.

상승 경고 Logistic에서 제거한 상태 경과시간은 B1에는 남아 있다. B1의 경과시간 SHAP이 크다는 결과를 해당 변수가 성능에 유리하다는 뜻으로 해석하지 않는다. 변수 기여는 모델이 그 입력을 사용한 정도를 설명하며, 도움이 되는지의 판단에는 별도의 같은 조건 입력 비교가 필요하다.

## 4.13 삽입 본문: 최대전력 HGB의 변수 기여 해석

최대전력 값을 예측하는 HGB B0·B1을 TreeSHAP으로 설명했다. 학습된 트리 경로의 관측 비중을 기준으로, 각 예측을 기준값과 입력별 기여의 합으로 분해했다. 개발 기간은 평가 월 이전에 학습한 세 모델의 학습 밖 예측을, 후반기는 6월 말 고정 모델의 예측을 사용했다. SHAP 합과 기준값이 실제 HGB 예측을 복원하는지 모든 분석 시간에서 확인했다.

아래 값은 평균 절대 SHAP이며 원자료 전력값의 기록 척도로 표시했다. 확률·정확도 비율·오차 감소량은 아니다. 양·음의 기여가 평균에서 상쇄되지 않도록 절댓값을 사용했다.

| 개별 입력 | B0 개발 4~6월 | B1 개발 4~6월 | B0 후반기 7~8월 | B1 후반기 7~8월 |
|---|---:|---:|---:|---:|
| 직전 마지막 15분 전력 | 47.19 | 45.71 | 53.44 | 51.34 |
| 시간대 코사인 | 14.13 | 13.67 | 14.24 | 13.66 |
| 직전 최대 전력 | 1.60 | 1.54 | 1.54 | 1.38 |
| 시간대 사인 | 1.47 | 1.20 | 1.36 | 1.35 |

두 기간과 두 모델에서 직전 마지막 전력값과 시간대 정보가 가장 큰 기여를 보였다. 직전 마지막값은 최근 수준을, 시간대 사인·코사인은 하루 안의 위치를 나타낸다. 따라서 현재 회귀모델은 최근 전력 수준과 일중 패턴에 주로 의존한다. 시간대 코사인의 기여를 특정 설비의 작동이나 물리적 원인으로 해석하지 않는다.

여러 전력 입력이 비슷한 정보를 담을 수 있으므로, 개별 순위와 함께 변수군 기여도 확인했다. 아래 값은 먼저 한 행의 변수군 SHAP을 합한 뒤 그 절댓값을 평균한 것이다. 개별 평균 절대 SHAP을 더한 값과는 다르다.

| 변수군 | B0 후반기 평균 절대 기여 | B1 후반기 평균 절대 기여 |
|---|---:|---:|
| 과거 전력·전력 변화 | 54.45 | 53.79 |
| 달력 | 14.71 | 14.05 |
| 과거 생산량·생산 변화 | 0.46 | 0.60 |
| 추적 상태 | 해당 없음 | 1.50 |

과거 생산량도 사용했지만 이 설명에서의 기여 규모는 전력·시간대보다 작았다. 기여가 작다는 이유만으로 입력이 불필요하다고 판단하거나 제거하지 않는다. SHAP의 분배는 변수 간 중복 정보와 트리 구조에 영향을 받는다.

성능 민감도는 같은 월의 다른 날짜에서 같은 시각의 변수군 값을 가져오는 순열로 보완했다. 변수군 안의 입력은 함께 옮기고 10회 반복했다. 과거 전력군을 바꿨을 때 후반기 전체 MAE 증가량은 B0 51.14±5.43, B1 50.49±5.35였고, 생산군은 각각 0.54±0.07, 0.82±0.12였다. ±는 반복 간 표준편차이며 신뢰구간이 아니다. 이 순열은 시간대를 고정하므로 달력군의 값은 요일·평일 구분에 대한 민감도로만 읽고, 시간대 정보의 중요도 비교에는 사용하지 않는다. 서로 다른 변수군 사이의 관계를 깨뜨릴 수 있으므로 증가량을 실제 입력 제거·재학습 효과로 해석하지 않는다.

날씨 포함 고정 모델에서도 후반기의 날씨군 평균 절대 SHAP은 B0 0.29, B1 0.23으로 나타났다. 개별 기온 기여는 각각 0.13, 0.12였다. 날씨를 모델이 조금 사용했다는 사실과, 날씨가 예측을 개선했다는 결론은 다르다. 입력 채택은 앞의 동일 조건 성능 비교로 판단한다.

기존 Logistic 로짓 분해는 상승 경고가 왜 발생했는지를 설명하고, 이번 HGB SHAP은 최대전력 예측값이 어떤 입력에 의해 높아지거나 낮아졌는지를 설명한다. 두 결과의 단위와 역할을 구분하며 인과관계나 현장 절감 효과로 확대하지 않는다.
