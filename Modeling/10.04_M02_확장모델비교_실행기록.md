# M02 재실행: 확장 모델과 두 가지 예측 목적의 비교

## 이전 결과에서 생긴 질문

초기 M02에서 기본 A 입력의 HGB는 전체 최대전력 MAE 6.738로 직전 값 기준 13.793보다 좋았다. M03에서는 마지막 값 B를 추가하면 MAE가 6.191로 줄었으나 상승 전환과 낮은 구간 유지에서는 개선되지 않았다. 사용자는 이 결과만으로 HGB를 고정하기보다 다른 모델과 튜닝·앙상블을 비교하고, 전체 정확도와 중요한 최대 시간의 정확도를 함께 평가하도록 요청했다.

따라서 이번 회차는 별도 M02-2가 아닌 **M02의 확장 재실행**이다. 기존 M02·M03의 코드·표·원고는 이전 판단의 근거로 보존한다. 중단된 `m022` B 입력 부분 실행은 이 회차의 선택이나 성능표에 사용하지 않는다. 이미 개발 결과를 확인한 뒤 설계를 바꾼 것이므로 새로운 독립 시험으로 표현하지 않는다.

## 실행 전에 고정한 조건

- 입력 A 17개, 주 목표 다음 한 시간의 네 전력값 중 최댓값, 모든 모델의 공통 평가 시각 2,184개.
- 외부 개발 비교: 1~3월 학습→4월 720시간, 1~4월→5월 744시간, 1~5월→6월 720시간. 월별 평가의 모든 적격 시간을 사용한다.
- 내부 튜닝: 평가월 이전 자료만 사용해 1월→2월, 1~2월→3월처럼 학습 범위를 늘린다. 4월 평가의 내부 검증은 2·3월, 5월은 2·3·4월, 6월은 2·3·4·5월이다. 무작위 분할을 하지 않는다.
- 학습한 모델은 외부 평가월 동안 고정하고 관측이 끝난 시차 입력만 매시간 갱신한다. 다음 한 시간 예측이며 월 전체의 사전 예측이 아니다.
- 핵심 튜닝 5계열: HGB, XGBoost, LightGBM, CatBoost, ExtraTrees. 기존 Ridge·Elastic Net·SVR·HGB와 직전·전날·전주 단순 기준을 참조로 유지한다. 기존 참조 모델의 설정은 과거 개발 결과로 선택됐으므로 내부 검증에서 새로 선택한 모델과 이력이 다름을 밝힌다.
- 앙상블: 튜닝한 5모델의 동일 가중 평균, 내부 검증 점수 상위 3모델의 비음수 가중 평균. 구성원과 가중치는 외부 평가 전에 고정한다.
- Optuna 각 모델·외부 월에 기본 30회. 30회까지의 내부 선택 점수가 최초 20회의 최선보다 1% 이상 좋아졌을 때만 50회로 확장한다. 가중치 탐색은 50회. 외부 성능을 보고 탐색 범위나 횟수를 늘리지 않는다.
- 7~8월은 이번 모델 선택·튜닝에 사용하지 않는다. 현재 흐름의 후속 M05 구간이며, 과거 관찰 이력 때문에 완전히 보지 않은 독립 시험이라고 부르지 않는다. 자료 범위 밖의 9월은 편입하지 않는다.

## 지표와 선택 규칙

첫 주지표는 전체 시간 MAE, 두 번째는 **실제 일별 최대 시간의 MAE**다. 실제 최대가 동률이면 그 날짜의 합계 가중치가 1이 되도록 나눈다. 외부 91일을 같은 비중으로 평가하고, 내부 검증에서는 적격 24시간이 모두 있는 날짜만 최대 시간 지표에 포함한다. 최대 시각은 사후 평가를 위해서만 사용하며 예측 입력에 넣지 않는다.

Optuna에는 두 MAE를 별도 목적값으로 전달하고 파레토 후보를 보존한다. 상충할 때의 선택 기준은 다음과 같다.

`선택 점수 = max(전체 MAE / 직전 기준 전체 MAE, 최대 시간 MAE / 직전 기준 최대 시간 MAE)`

분모는 내부 튜닝이면 같은 내부 기록의 직전 값 기준, 최종 개발 비교이면 같은 외부 기록의 직전 값 기준이다. 두 지표를 먼저 각각 공개하며 한쪽의 큰 개선이 다른 쪽의 부진을 숨기지 않도록 더 나쁜 상대오차를 줄인다. 이는 임의의 7:3 비용 가중치를 만들지 않기 위한 비교 규칙이며, 실측한 현장 손실함수나 모든 운영 목적의 최적값은 아니다.

최종 개발 선택에서는 다른 방법에 두 지표 모두 뒤지는 후보를 제외하고, 최선 선택 점수의 1% 안이면 기존 HGB, 단일 모델, 동일 평균, 가중 평균의 순서로 단순한 방법을 우선한다. 단일 계열의 동률 우선순위는 조건 JSON에 고정했다. 과소·과대예측, RMSE, 월별·반복 배열별·전환별 오차는 별도 진단으로 제시한다. 분류 라벨을 만들지 않은 회귀에서 AUROC·AUPRC를 주지표로 사용하지 않는다.

## 결과에 따른 다음 선택

선택 모델 또는 설정이 초기 HGB A와 달라지면, 월별로 선택한 **A 튜닝 설정을 고정한 채** M03 A/B를 다시 비교한다. 계절 시차 C_A/C_B와 보조 평균 목표도 동일 설정으로 확인한다. 입력을 바꿀 때마다 재튜닝하면 입력 효과와 설정 변경이 섞이므로 이 비교에서는 재튜닝하지 않는다. 결과에 따라 마지막 값·계절 시차의 채택 여부를 갱신한다. 새로운 모델이 개선하지 못하면 기존 결과를 유지하고 확대의 실익이 없었다고 기록한다.

### HGB도 튜닝했는가: 두 차례의 설정 선택

초기 M02는 최대 잎 수 7·15의 두 후보만 비교하고 나머지를 고정했다. 확장 M02는 HGB도 Optuna 대상에 포함해 학습률·반복 횟수·최대 잎 수·잎의 최소 표본 수·L2 규제를 탐색했다. 4·5·6월용 각각 30회, 총 90회이며 평가월 이전의 시간순 내부 검증으로 설정을 선택했다.

| 구분 | 전체 MAE | 일별 최대 시간 MAE |
|---|---:|---:|
| 초기 후보 비교에서 선택한 기존 HGB | 6.738 | 11.751 |
| Optuna 튜닝 HGB | 6.963 | 13.251 |

유지한 설정은 `max_leaf_nodes=15`, `max_iter=150`, `learning_rate=0.05`, `min_samples_leaf=20`, `l2_regularization=1.0`이며 난수 시드 42·조기 종료 미사용이다. 이번 외부 개발 평가에서는 Optuna 설정의 두 오차가 더 커 기존 설정을 유지했다. 기존 설정은 초기 개발 결과에서 선택했고 Optuna는 평가월 이전 내부 검증으로 선택했다는 차이를 함께 기록한다. 현재는 개발 후보 유지 판단이며 후반기 성능 확인은 남아 있다.
