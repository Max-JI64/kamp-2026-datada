# HGB 변수 기여와 과거 날씨의 추가 가치 검증

## 작업 범위와 이전 근거

Analysis 3.3은 날씨·전력의 조건부 관계를 확인했지만 예측 개선을 검증하지 않았다. Modeling 4.3은 날씨 D를 실행하지 않았고, 4.13의 영향요인 분석은 상승 경고 Logistic의 로짓 분해였다. 이에 과거 날씨 추가의 성능 차이와 최대전력 HGB의 입력 기여를 확인했다. 기존 원고는 팀원이 작성 중이므로 [기존 절 삽입용 본문](보완_변수기여와날씨선택근거_삽입용.md)을 별도로 작성했다.

사용 자료는 기존 data 폴더의 원자료와 검증된 중간 결과다. 기존 모델·원고·결과표·제출 폴더를 변경하지 않고 `Modeling/tables/feature_weather_audit`에 새 산출물을 저장했다. 설명 대상은 기존 B0 18입력, B1 31입력이며 상승 경고 Logistic과 그 경계는 고정했다. 현재 방법의 성능 탐색을 재개하거나 최종 모델을 자동 교체하는 작업은 아니다.

## 비교 조건과 결과 전 판단 기준

기존 B0·B1 모델 8개를 다시 불러와 저장 예측과 일치를 확인한 뒤 날씨 모델만 8회 학습했다. 실제 학습 행과 정답 확정 시점은 동일하다.

| 평가 | 학습 시간 수 | 평가 시간 수 | 학습 범위 |
|---|---:|---:|---|
| 4월 | 1,414 | 720 | 2~3월, 정답 확정은 4월 시작 전 |
| 5월 | 2,134 | 744 | 2~4월, 정답 확정은 5월 시작 전 |
| 6월 | 2,878 | 718 | 2~5월, 정답 확정은 6월 시작 전 |
| 7~8월 | 3,598 | 1,344 | 2~6월, 6월 말 1회 학습 후 고정 |

개발 평가 2,182시간은 지속 정답이 확인되는 기존 B0·B1 공통 범위다. M03의 2,184시간과 혼합하지 않는다. 6월 마지막 두 시각을 포함한 새 전체 범위로 확장하지 않았다. 후반기는 과거 정보가 완전한 회귀 시간 1,344개를 유지하며 미래 지속 정답이 불완전한 시간도 회귀 평가에는 남겼다. 지속 상승 시작 지표는 정답이 확인된 시작만 사용한다.

HGB는 최대 잎 15, 반복 150, 학습률 0.05, 최소 잎 표본 20, L2 1, 조기 종료 미사용, 시드 42를 유지했다. 날씨 4개는 정확한 t−1 시각으로 연결하고 원자료와 전부 대조했다. 학습 중앙값으로 결측을 처리하고 학습에서 결측이 있었던 열에만 표시를 추가했다. 모든 baseline 행을 남겼으며 튜닝·보간·예측값 절단은 하지 않았다. 세 개발 모델의 풍속 결측은 학습에 없고 6월 평가에 2시간 있었다. 고정 후반기 모델의 풍속은 학습 2시간·평가 1시간 결측이며 다른 날씨 열의 결측은 해당 비교 범위에서 없었다.

기존 구성을 교체할 개발 기준은 결과를 보기 전에 기록했다. 전체 MAE 최소 1% 감소, 일별 최대 MAE 악화 1% 이하, 세 개발 월 중 두 달 이상 전체 MAE 비악화다. 두 모델 모두 기준을 통과하지 못했다. 7~8월은 이미 관찰한 탐색적 후속 기간이며 독립 최종시험이나 재튜닝 근거로 사용하지 않는다.

## 날씨 비교의 핵심 결과와 판단 갱신

| 모델 | 개발 전체 MAE 제외→포함 | 4월 증가율 | 5월 증가율 | 6월 증가율 |
|---|---:|---:|---:|---:|
| B0 | 6.267→6.716 | 7.00% | 8.97% | 5.51% |
| B1 | 6.392→6.692 | 5.66% | 2.74% | 5.27% |

날씨 제외 선택의 근거는 약한 조건부 관계라는 우선순위 판단에서, 같은 입력·설정 비교에서 개발 오차가 증가했다는 근거로 보강됐다. 추가로 학습했을 때 트리 구조가 바뀌므로 오차 차이를 기온 등의 인과효과로 해석하지 않는다.

후반기 B1 전체 MAE는 7.994→7.854로 1.75% 감소했고 경고 7시간은 13.981→13.092로 6.36% 감소했다. 반면 B0는 전체 MAE 6.335→6.409로 1.18% 증가했다. 따라서 날씨가 모든 조건에서 나쁘다는 해석은 기각한다. 기존 경고를 그대로 두고 B0는 날씨 제외·B1만 날씨 포함으로 결합한 최소 대조도 수행했다. 새 학습은 없었고, 전체 MAE는 개발 6.2595→6.2630으로 악화, 후반기 6.3172→6.3126으로 소폭 개선했다. 개발 경고 12시간은 7.47% 악화했으므로 후반기 7시간의 개선만으로 채택하지 않는다.

이 대조는 두 모델에 동시에 날씨를 추가한 결합과 다르다. 동시 추가 결합은 후반기 전체 MAE 6.3172→6.3876으로 1.11% 증가하고 일별 최대 MAE는 12.574→12.448로 1.00% 감소했다. 전체와 최대 시간 목표 사이의 상충을 보존했다. B1만 추가한 결합의 후반기 상승 시작 13건 MAE는 18.205→17.727로 2.63% 감소했지만 개발 상승 18건에서는 17.007→17.438로 2.54% 증가했다.

## HGB 설명 방법과 적용 범위

정확한 tree-path-dependent TreeSHAP을 사용했다. 기준 분포는 각 기존 모델에 저장된 학습 경로별 관측 수이며, 평가 자료로 새 기준 분포를 학습하지 않는다. 원래 예측을 분해하며 SHAP 합+기준값과 실제 예측을 매시간 대조했다. 기존 개발 B0·B1 6개, 후반기 B0·B1 2개, 후반기 날씨 B0·B1 2개를 합한 모델 10개의 9,740개 모델별 시간 예측을 설명했다. 서로 다른 모델이 같은 시각을 설명한 경우 각각 세었으므로 고유 관측 시간 수가 아니다.

개별 변수는 평균 절대 SHAP으로 정렬한다. 개발 요약은 월별 평가 시간 수로 가중했고, 상승 시작과 실제 경고 조건은 각 조건의 시간 수로 가중했다. 변수군은 행별 SHAP 합의 절댓값 평균이다. 상관된 전력 변수들 사이에서 기여가 나뉠 수 있으므로 개별 순위를 독립적 공정 영향력으로 해석하지 않는다. 평균 절대 SHAP은 예측값 기여이고 오차 기여가 아니다.

변수군은 달력 11개, B0 과거 전력 5개·생산 2개이며 B1에는 전력 변화 7개·생산 변화 1개·추적 상태 3개·분류 가용 표시 2개가 추가된다. 날씨 결측 표시도 날씨군에 포함한다. 기존 B0·B1 양쪽에서 직전 마지막값과 시간대 코사인이 가장 큰 기여를 보였다. 경고 7시간에서는 B1의 마지막값-평균 차이와 직전 평균 변화의 기여가 커져 전체 시간 순위와 차이를 보였다.

순열 민감도는 같은 월 안의 날짜를 무작위 대응시켜 같은 시각의 변수군 전체를 함께 옮겼다. 하루 안의 순서와 같은 군 내부 관계는 유지하며, 대응 날짜에 해당 시각이 없으면 원래 값을 유지한다. 시드 42~51로 10회 반복하고 실제 변경 비율도 원표에 기록했다. 시간대를 고정했으므로 달력군 순열은 시간대·월 중요도를 시험하지 않는다. 과거 전력군의 MAE 증가가 컸으며 SHAP에서 확인한 최근 전력 의존과 일치했다. 생산군 민감도는 더 작았다.

B1 추적 상태군은 후반기 순열 후 평균 MAE가 0.62 줄었다. 상태군의 SHAP이 크더라도 성능에 유리하다는 뜻은 아니라는 단서다. 그러나 입력을 제거하고 재학습한 실험이 아니며 다른 군과의 관계를 깨뜨린 교란 결과이므로 B1 상태 입력 제거를 권고하지 않는다. 실제 경고 7시간에서의 상태군 순열 MAE 변화는 −0.42±1.13으로 반복 방향도 섞였다. 이번 질문은 기여 해석이며 B1 재설계는 수행하지 않았다.

날씨군의 후반기 평균 절대 SHAP은 B0 0.29·B1 0.23이었고, 전체 시간 순열 MAE 변화는 각각 −0.014·−0.012로 작은 수준이었다. 실제 경고 7시간에서는 날씨군 교란 후 B1 MAE가 평균 0.54 증가했다. 전체 평균과 작은 조건의 민감도가 다름을 보존하고, 입력 채택은 개발 포함·제외 비교로 판단했다.

## 실행·수정·검증 기록

1. 결과 전 조건을 고정하고 기존 8개 모델의 예측을 대조했다. 비교 모델마다 과거 날씨를 추가해 8회 학습했다.
2. 첫 interventional TreeSHAP은 원래 4월 B0에서 합산 검증에 실패했다. 변환 모델 자체의 예측은 원래 sklearn과 정확히 일치했지만 기여 합의 최대 오차는 14.8738이었다. 같은 모델의 tree-path-dependent 방식은 최대 오차 2.63×10⁻¹³으로 실제 예측을 복원했다. 해석 방법만 변경하고 잘못된 기여값은 결과에 사용하지 않았다. 최초 코드·조건은 보존했다.
3. TreeSHAP 모델 10개 모두 내장 합산 검사와 실제 예측 대조를 통과했다. 최대 복원 오차는 4.55×10⁻¹³이었다. 검사 실패를 숨기거나 생산 계산의 합산 검사를 끄지 않았다.
4. 날씨 모델 8개를 별도로 다시 학습해 저장 예측과 일치를 확인했다. 저장 예측에서 전체·조건별 오차 186행을 다른 계산 흐름으로 다시 확인했다. 결측 처리 입력의 정확한 재구성과 현재 G1 결합 예측도 대조했다. 현재 G1과 원래 결과의 최대 차이는 5.68×10⁻¹⁴이었다.
5. 기존 상세·압축 Modeling 원고와 Analysis 상세 원고의 해시가 시작 전과 동일함을 확인했다. 외부 제출·모델 교체·원고 통합은 수행하지 않았다.

정규 CPython 3.13.1, numpy 2.2.6, pandas 3.0.1, scikit-learn 1.7.1, SHAP 0.51.0에서 실행했다. 주 분석 신규 학습 8회·검증 재학습 8회이며, 기여 계산과 B1만 날씨 결합에는 새 학습이 없다. 패키지를 설치하거나 변경하지 않았다.

기존 결과를 덮어쓰지 않도록 완료된 출력 폴더에서 비교를 다시 실행하면 중단한다. 다른 출력 폴더로 재현할 때는 스크립트의 OUT을 새 경로로 지정하고 freeze→run→revise_shap→explain→verify 순서로 실행한 뒤 집계·결합 코드를 같은 새 경로에 맞춘다. 원래 모델·전처리 CSV에 의존하는 이번 추가 분석의 재현 경로이며, 전체 원자료 분석의 한 명령 재현기를 새로 교체한 것은 아니다.

날씨 제외 선택을 검증하는 질문에는 현재 고정 조건의 개발 결과로 답했다. HGB 입력 기여 질문에는 두 기간·두 모델의 실제 SHAP과 변수군 민감도로 답했다. 남은 한계는 다른 시차·튜닝 구성의 날씨 가치, B1 상태 입력 제거의 효과, 독립 미래 기간의 성능이다. 이번 범위에서 이를 새 탐색으로 늘리지 않는다. 기존 조건의 날씨 채택 기준 실패와 작은 후반기 예외를 함께 남기고 분석을 종료한다.
