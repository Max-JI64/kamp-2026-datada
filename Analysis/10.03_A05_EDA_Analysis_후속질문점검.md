# EDA·Analysis 후속 질문 점검

2026-10-03. 현재 EDA·데이터 원고, 승인된 Analysis 3.1~3.4와 연결된 실행 기록을 대조했다. 백업 자료는 사용하지 않았다. 이번 작업은 기존 근거 검토이며 새 관계 계산·학습·원고 확장은 하지 않았다.

**판단: Modeling으로 넘어갈 수 있다. 새 Analysis 절을 의무적으로 추가할 근거는 확인하지 못했다. 다만 최초 계획의 일부 입력 비교와 과제 전체의 오류·활용 분석은 남아 있으므로, 모든 분석 질문을 해결했다고 선언하지 않는다.**

## Modeling 첫 단계에서 확정할 사항

1. **목표·정보 시점:** 우선 승인한 후보는 관측을 마친 한 시간 다음의 네 15분 값 중 최댓값이다. 기록 단위의 전력값 예측으로 기술하고 kWh·실제 비용을 임의로 붙이지 않는다. 원래 전력 수준 예측과의 연결을 위해 시간 평균을 함께 평가할지는 Modeling 설계에서 명시한다. 평균 예측을 이미 해결했다고 간주하지 않는다.
2. **단순 기준과 시차:** 직전 최대값, 전날 같은 시간의 최대값, 전주 같은 시간의 최대값을 시간 인덱스로 연결하고 유효 표본 수·누락 시 처리와 공통 평가 행을 정한다. 검증에서 단순 기준의 오차를 비교한다. 이는 새 상관계수 절을 만들기 위한 작업이 아니다.
3. **입력 가치:** 달력·과거 생산·과거 평균·과거 최대를 사용하는 기준과 마지막 15분 값 추가를 같은 모형·분할·평가 행으로 비교한다. 과거 날씨나 추가 시차는 별도 입력 묶음으로 비교해 마지막 값의 효과와 섞지 않는다. 모든 기법·변수 조합을 무한 탐색하지 않는다.
4. **시간순 검증과 반복:** 학습 자료 안에서 결측 처리·변수 선택·설정을 정하고, 실제 분할의 반복 배열 겹침·월별 결과를 확인한다. 7~8월은 이미 여러 분석에서 본 기간이므로 새 독립 시험이라고 부르지 않는다. 9월 336행은 현재 EDA·Analysis의 범위 밖이며 이번 점검에서 열거나 편입하지 않았다. 사용 여부와 평가 역할은 Modeling 설계에서 먼저 정해야 한다.
5. **정보 누출:** 목표 시간 실측 생산량·날씨·평균·최대 및 목표 전력으로 계산되는 공장인원 등을 입력으로 쓰지 않는다. 원자료 시각 오류를 행 순서로 복원하거나 누락 시간을 건너뛴 행을 1시간 시차로 취급하지 않는다. 실제 관측 지연이 미식별인 점과 기록 가용성 가정을 명시한다.

## 예측 결과가 나온 뒤 해야 할 분석

- **실패조건:** 전체 MAE와 함께 생산량 0→양수·양수 지속·0 지속·양수→0, 낮은 전력의 지속·변화, 월·평일/주말·시간대별 오류와 표본 수를 확인한다. 관측 변동이 크다는 사실을 예측오차가 크다는 결과로 대신하지 않는다. 처음부터 모든 조건의 교차표를 만들지 말고 오차가 집중된 범위에서 원인을 진단한다.
- **최대전력 과소예측:** 실제 일별 최대 시간의 과소·과대예측 크기, 전체 오차, 기간별 개선을 함께 확인한다. 일별 상대적 최대는 낮은 전력의 날에도 존재하므로 최대값 자체의 크기도 함께 제시한다. 과대예측을 늘려 얻은 일방적인 과소예측 감소를 성과로 주장하지 않는다.
- **활용과 저감방안:** 과제공개의 생산일정·가동 시점 조정 제안은 미완료다. 예측에서 실제로 포착 가능한 시간과 오차를 바탕으로 점검·조정 검토 대상을 제안한다. 설비별 이동 가능 부하·운영 제약이 식별되지 않으므로 실제 최적 일정·절감량·비용 절감을 입증했다고 쓰지 않는다. 기존에 제외한 가정 기반 부하 재배치를 자동으로 재개하지 않는다. 하루 사전 순위가 필요하면 동일 예측 시점과 후보 시간범위를 먼저 정한다.

## 종료 판단

추가 날씨 변환, 새로운 피크 임계값, 더 큰 상관을 얻기 위한 조건 변경, 이유 없는 기법 추가는 현재 결과에서 요구되지 않는다. 다음 답변을 얻는 데 필요한 것은 예측값이므로 **Analysis의 선행 관계 탐색은 마무리하고 Modeling의 예측 문제·검증 설계를 시작하는 것이 적절하다.** 모델 오류에서 새로운 질문이 생기면 해당 근거에 한해 Analysis를 다시 보완한다.
