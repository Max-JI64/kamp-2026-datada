# EDA 이후 Analysis 계획

2026-10-03 사용자 지정 후속 분석이다. 현재 상태는 **계획 기록, 신규 분석 미실행**이다. 아래 세 질문은 Analysis에서 다룬다. 기존 백업의 분석·모델 결과를 이번 실행 결과로 간주하지 않는다.

출발점은 [EDA 원고](<../EDA/02_EDA_원고.md>)의 2.1 ~ 2.5다. 현재 제공된 `data` 자료만 사용하며, 이전에 확인한 수치와 예외를 근거로 다음 순서로 진행한다. 방법과 비교 조건은 실행 전에 구체화하고, 결과를 보고 유리한 조건으로 반복 변경하지 않는다.

## A01. 생산 기록과 시간대를 고려해도 날씨·전력 관계가 남는가?

- **이전 근거:** EDA 2.3에서 8월 기온·평균 전력의 Spearman 상관은 전체 −0.076, 생산량 양수 383시간에서는 0.599였다. EDA 2.4에서는 평일 4,104시간 중 747시간이 20 ~ 26의 낮은 전력에 해당했고, 그중 92시간은 생산량이 양수였다. 생산량 0, 낮은 전력, 실제 휴무를 동일하게 취급할 수 없다.
- **질문:** 날씨와 전력의 관측 관계가 생산 기록·시간대·시기의 구성 차이를 고려해도 나타나는가? 어떤 조건에서 관계가 달라지는가?
- **최소 분석:** 평일을 중심으로 조건별 표본 수와 변수 범위를 확인한 뒤 생산 기록·시간대·시기를 함께 고려한 관계를 비교한다. 낮은 전력을 포함한 결과와 수준별 보조 결과를 함께 확인한다. 한 기상변수를 해석할 때 다른 기상변수와의 관계도 고려한다. 비교 가능한 조건의 기록이 부족하면 그 범위를 명시한다.
- **판단:** 관계가 조건별로 유지되는지, 약해지는지, 방향이 달라지는지 확인한다. 낮은 전력 구분은 목표값에 따른 사후 관측 구분이므로 인과효과나 예측 시점의 가용 정보로 해석하지 않는다. 원인이나 예측 성능 개선은 이 관계 비교만으로 확정하지 않는다.
- **후속 조치:** 관계의 범위를 정리한 후, 예측 당시 이용할 수 있는 과거 기상·생산 정보에 한해 Modeling의 입력 비교 후보로 연결한다. 목표 시간의 실측 날씨·생산량을 미리 안다고 가정하지 않는다.
- **근거 파일:** [8월 생산 기록별 상관](<../EDA/tables/restart_relations_august_context.csv>), [평일 생산 기록 대조](<../EDA/tables/weekday_power_levels/production_context.csv>).

## A02. 이전 전력은 다음 시점의 전력을 얼마나 설명하는가?

- **이전 근거:** EDA 2.2는 같은 시각에 반복되는 하루 패턴을, 2.4는 낮은 전력이 나타나는 네 시간 조합을 확인했다. 그러나 이것만으로 직전 전력과 다음 전력의 관계, 수준이 바뀌는 시점의 예측 가능성까지 알 수는 없다. 데이터 원고 1.5에는 날짜가 달라도 하루 전력 배열이 반복된다는 관찰도 있다.
- **질문:** 직전 시간·전날 같은 시간·전주 같은 시간 중 어떤 과거 기록이 현재 전력과 연결되는가? 낮은 전력이 이어질 때와 수준이 바뀔 때 관계가 다른가?
- **최소 분석:** 먼저 예측 대상과 예측 간격을 명시한다. 실제 날짜·시간 차이에 따라 1시간·24시간·168시간 전 기록을 연결하고, 시간 오류나 누락을 건너뛴 행을 연속 기록으로 취급하지 않는다. 각 비교의 유효 표본 수, 값의 관계와 차이 분포를 확인한다. 낮은 전력의 지속·전환은 사후 진단으로 구분하며, 동일 배열 반복의 영향을 보조 점검한다.
- **판단:** 전체 관계가 달력 패턴이나 동일 배열 반복만으로 설명되는지, 전환 구간에서 크게 약해지는지 구분한다. 다음 전력의 실제 상태를 미리 알고 예측 대상을 선택하지 않는다.
- **후속 조치:** 확인된 관계를 과거 입력과 단순 예측 기준선의 후보로 정리한다. 실제 예측 성능과 입력 조합 선택은 시간순 검증을 적용한 Modeling에서 평가한다. 낮은 전력 다음의 재상승도 평가 대상에 포함한다.
- **근거 파일:** [날짜별 전력·변화](<../EDA/tables/daily_repetition/daily_values.csv>), [평일의 시간 조합](<../EDA/tables/weekday_power_levels/daily_hour_patterns.csv>), [데이터 원고](<../EDA/01_데이터_원고.md>).

## A03. 높은 15분 전력은 어떤 조건에서 나타나며 시간 평균에 얼마나 드러나는가?

- **이전 근거:** EDA 2.5는 전체 정상 날짜에서 시간대별 구간 위치의 차이와 반복 비율을 확인했다. 이 히트맵은 각 구간에서 같은 시간 평균을 뺀 값이므로 절대적으로 높은 전력의 발생 조건이나 최대와 평균의 차이를 직접 설명하지 않는다.
- **질문:** 각 시간의 네 전력값 중 최댓값이 높을 때 시간 평균도 함께 높은가? 최대와 평균의 차이가 큰 기록은 어떤 시간대·생산 기록·날씨 조건에서 나타나는가?
- **최소 분석:** 같은 행의 네 값으로 정확한 산술평균과 최댓값, 최대−평균 차이를 계산한다. 전체 값의 관계와 분포부터 확인하고 시간대·평일/주말·생산 기록·기상 조건별 차이를 살펴본다. 높은 값이 한 구간에 집중되는지 여러 구간이 함께 높은지도 이 질문에 필요한 범위에서 비교한다.
- **판단:** 높은 평균 수준과 한 구간의 상대적인 상승을 구분한다. 상위 5%나 기존 187을 공식 피크 기준으로 선결정하지 않는다. 분류 기준이 필요해지면 목적과 산정 근거를 먼저 명시한다. 단위·요금 산정 규칙이 식별되지 않은 상태에서 실제 비용으로 환산하지 않는다.
- **후속 조치:** 평균 예측만으로 설명하기 어려운 부분을 확인하고, 15분 값 또는 시간 내 최댓값 예측의 필요성과 평가 항목을 Modeling에 전달한다. 성능·비용 절감 효과는 실제 검증 전 주장하지 않는다.
- **근거 파일:** [시간대별 네 구간 집계](<../EDA/tables/slot_time_patterns/hour_slot_summary.csv>), [구간 배열별 날짜 수](<../EDA/tables/slot_time_patterns/within_hour_profiles.csv>).

## 실행 기록 방식

각 질문을 실행할 때 코드·결과표·그림과 해석 문서를 이 폴더 안에서 연결한다. 이전 근거, 이번 비교 조건, 핵심 결과, 기존 해석의 유지·수정, 다음 작업 또는 종료 근거를 기록한다. 결과가 기존 EDA 해석을 바꾸면 해당 절도 수정한다. 현재 문서는 후속 범위를 지정한 것이며, 세 분석을 수행했거나 전체 분석을 완료했다는 의미가 아니다.
