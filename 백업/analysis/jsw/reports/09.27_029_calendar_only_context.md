# 029 — 생산 상태를 빼고 달력만 맞춘 기간 비교

작성: 2026-09-27 | 005 감사에서 발견한 미해결 질문

## 이전 근거 → 질문 → 선택

[005](09.27_005_period_context.md)는 182 이상 고전력 시간 비율이 1~6월 5.41%, 7~8월 15.28%이고, `시간×주말×같은 시간 생산 양수 여부`를 맞춰도 5.45%→15.05%라고 보고했다. 그러나 **같은 시간 생산은 관측 후 결정되는 변수**이고 일부 교차층 표본도 작았다. 생산 상태를 쓰지 않고 `시간(0~23)×주말 여부`만 맞춰도 이 기간 차이가 남는가?

[실행 전 설정](../tables/09.27_029_frozen.json)에 004의 182 기준·정상 시각 1~8월·두 기간·공통층 가중 원칙을 고정했다. 각 기간에서 관측된 해당 층의 비율을 두 기간 합계 노출수로 가중했다. 시작 사건은 직전 시간이 182 미만인 적격 시간만 분모로 썼다. 반복 전력 프로필 역빈도 가중도 별도로 확인했다. 새로운 임계값이나 계층을 결과에 맞춰 고르지 않았다.

## 판단 갱신 → 종료 근거

005의 **관측 기간 차이가 사후 생산 변수에 조건을 걸어서만 생긴 것은 아니다.** 달력만 맞춘 비교에서 고전력 시간과 시작 비율의 방향이 유지되고, 작은 `시간×주말×생산` 층 문제도 이 비교의 고전력 시간에는 없다. 앞선 “기간의 기술적 차이”는 유지하되, 달력 표준화가 기간 차이의 **원인**이나 계절·설비·생산 변화의 효과를 식별하지는 못한다. 7~8월도 이미 탐색한 자료이고, 반복 프로필·원관측 여부와 생산량 의미가 확인되지 않았다.

이에 따라 같은 CSV에서 군집 수, 기준값, 달력층을 더 바꾸며 원인을 찾는 반복은 중단한다. 남은 실제 원인/운영 질문은 [028 감사](09.27_028_analysis_audit.md)의 자료 필요 항목으로 보류한다. 원본 직접 재집계와 아티팩트 연결 검사는 [028 검증 기록](../tables/09.27_028_audit_verification.json)에 남긴다.
