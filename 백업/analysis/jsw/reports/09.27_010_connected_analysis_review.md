# 010 — 제공처 설명 전 분석 30개 후보의 실행·판단 종합

작성: 2026-09-27 | 004~009의 연결된 결과 종합과 독립 검증

후속: 사용자의 추가 진행 요청으로 기존 결과의 남은 기술 질문을 011~015에서 분석했다. 현재 입구는 [016 후속 종합](09.27_016_followup_review.md)이다. 아래 종료 판단은 30개 후보를 정리한 당시의 범위다.

## 실행 범위

사용자가 [30개 후보](../ANALYSIS_OPTIONS.md)의 진행을 요청했다. 후보를 질문에 따라 여섯 회차로 묶어 실행했다. 이미 확인한 정보는 재사용·전수 확인했고, 비교 범위나 안정성이 부족한 결과는 그 한계를 판정했다. 아래의 **실행 완료는 원인·운영 효과가 입증됐다는 뜻이 아니다.** 예측 모델을 새로 학습해 점수를 개선하는 작업은 하지 않았다. FA·군집 등은 통계 구조를 설명하는 분석으로 수행했다.

기본 범위는 1~8월 정상 시각 5,784시간·241일이다. 009에서만 범위를 명시적으로 넓혀 시각 오류를 포함한 원본 6,168행의 비시간 품질과 정상 9월 336시간을 기술 비교했다. 기존 7~8월·9월은 이미 탐색했으므로 새 독립 시험이 아니다. 원본·프로필·모든 기준을 보존했다.

## 이전 결과 → 실행 → 해석 변화

1. **002의 기간 차이 → 004 기준·사건 분석:** 기준 176·182·188에서도 7~8월의 높은 시작률과 긴 지속이 유지됐다. 기준 182의 사건별 초과값 합 중앙값은 7→16이다. 기간 차이를 한 임계값이나 소수 사건만의 현상으로 설명하기 어렵다.
2. **004의 유지되는 차이 → 005 구성·영향 검증:** 시간·주말·현재 생산 상태의 공통 구성에서도 고전력 비율은 5.45%→15.05%이고 프로필 가중 후 5.80%→14.65%다. 한 월·주·프로필을 제외해도 방향이 유지됐다. 그러나 상위값 상승과 평균 감소가 함께 있어 모든 전력이 일괄 상승했다고 설명하면 안 된다.
3. **005의 평균·꼬리 차이 → 006 시간 진단:** 단일 분할의 최상 날짜는 평균 7/31, 고전력 시간 6/14, 초과값 합 6/28로 달랐다. 주기 잔차도 구간·주기에 민감하다. 7/1을 실제 원인 변화 날짜로 고정하지 않는다.
4. **조건만으로 설명되지 않는 사건 → 007 관계 검토:** 생산량 구간의 단순 차이는 컸지만 7~8월 네 구간의 공통 시간층은 2개·62시간뿐이다. 기상 잔차 상관은 반복 가중 후에도 작고 상위값 관계는 생산 상태·기간에 민감하다. 생산량·날씨를 보편적 원인으로 확정하지 않는다.
5. **원인이 남는 배열 차이 → 008 구조 요약:** 원척도 첫 주성분은 분산 83.3%를 설명하고 하루 평균과 상관 0.983·0.990이다. FA의 첫 요인도 공통 전력 수준을 주로 요약한다. 군집은 기간에 민감해 실제 운영 상태로 채택하지 않는다.
6. **해석과 범위의 제한 → 009 품질·기간 확장:** 시각 오류 48행에도 고전력 기록 10개가 있고, 저장 평균의 반올림은 기준 182에서 13행 분류를 바꾼다. 9월 시작률은 7.02%로 7~8월과 비슷하지만 다시간 사건 비중은 42.9%로 다르다. 시간 오류는 복원하지 않고 9월을 독립 시험으로 부르지 않는다.

## 채택할 설명과 보류할 설명

**현재 보고서에 쓸 수 있는 설명:** 탐색 기준을 바꿔도 7~8월의 높은 고전력 빈도·지속이 보인다. 관측 시간·생산 구성과 단일 반복 그룹만으로 차이를 설명하지 못한다. 평균과 최대·상위값의 목적이 다르다. 기록 수준·배열의 통계 요약은 가능하며 타입과 관계의 안정성에는 제한이 있다.

**확정할 수 없는 설명:** 설비별 원인·동시 가동·공정 전환, 실제 에너지 효율·사람 수·절감액, 일정 이동의 효과, 공식 피크 기준과 운영 경보 성능. 요인·군집·변화 후보·특이 기록은 해당 설명의 라벨이 아니다.

## 다음 단계·종료 기준

현재 30개 후보는 실행·재사용·자료 한계 판정까지 정리했다. 상관·층·군집 수·거리 기준을 더 바꿔 설명을 찾는 반복은 중단한다. 다음 필요한 정보는 **전력 네 값의 계측·시간 정의, 원본/증강 구분, 생산량 계획/실적·0의 의미, 시간 오류 정정 자료, 연결 가능한 설비·일정 이력**이다.

제공처 자료가 오면 그 정의가 현재 파일에 적용되는지부터 확인한다. 원관측과 같은 정의의 구간을 식별할 수 있을 때 004~005의 기간·심각도 차이를 해당 범위에서 재검토한다. 시각 오류가 정정되면 004·006·009의 영향을 받는 날짜·사건 경계만 갱신한다. 실제 조정 가능한 변수와 비교 가능한 기록이 있을 때 개입 질문을 새로 연다. 따라서 **설명 전 후보의 처리는 마쳤지만 전체 원인·운영 과제 분석을 완료한 것은 아니다.**

## 검증·수정 이력

004~009 최종 실행은 모두 정규 CPython 3.13.1·지정된 escalated Start-Process 경로에서 종료0이다. 009 최초 종료1은 저장 소수 오차 규칙의 프로젝트 assertion 실패였고, 독립 진단 후 원본 자릿수 기준으로 수정했다. Python 기동·패키지 실패가 아니다.

[독립 검증 코드](../scripts/09.27_010_verify_artifacts.py)는 원본의 정확한 시각 사전으로 이전 연결을 별도 구성해 시작139·85/분모4,108·1,218, 고전력455시간, 초과값 합4,215를 재현했다. 저장 층에서 표준화4조합 재계산, 241일 군집 배정·PCA기저 직교성, 반올림13행, 입력·설정 해시를 확인했다. 상위10일의 동점 경계·생산 조건별 지속 표를 기존 결과에서 보완했고 JSON의 비유한 메타데이터를 null로 저장했다.
