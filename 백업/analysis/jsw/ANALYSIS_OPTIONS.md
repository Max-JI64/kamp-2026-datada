# 제공처 설명 전의 추가 분석 후보

작성: 2026-09-27 | 상태: **후보와 실행 기준 정리, 새 계산 없음**

후속 상태: 이후 사용자 실행 요청에 따라004~009를 수행했다. 이 문서는 원래 후보 계획을 보존하며, 현재 실행·재사용·한계 판정은 [010 종합](reports/09.27_010_connected_analysis_review.md)을 따른다.

최신 검토: [036 전체 방법·후속 감사](reports/09.27_036_all_stage_analysis_audit.md)는 EDA·analysis·modeling의 기존 57개 보고서를 대조했다. 010의 후보 처리는 모든 후속 해석의 완료가 아니다. 남은 분포·공동 관계·PCA 잔차 질문과 우선순위는 036을 따른다. 이번 갱신은 문서 검토이며 새 데이터 분석을 실행하지 않았다.

후속 실행 상태: 사용자가 분석 진행과 해석용 FA를 요청하여 [037 분포](reports/09.27_037_distribution_followup.md)·[038 FA](reports/09.27_038_factor_followup.md)·[039 공동 관계](reports/09.27_039_joint_relationship.md)를 수행했다. 036의 PCA 잔차 제안은 FA 적재·재구성 잔차 질문으로 변경해 기록했다. 036은 작성 시점의 미실행 계획으로 보존한다.

## 범위

현재 자료는 전력 네 값·생산량·기상·달력 등이 있는 한 CSV다. 여러 파일의 결합이 분석의 필수 조건은 아니다. 동일 CSV에서 시간·일·사건·프로필 표를 만들어 연결하면 다른 분석 단위의 질문에 답할 수 있다. 단위·측정 범위·증강·계획/실적은 제공처 설명 전 미확인으로 남긴다.

[EDA 020](../../EDA/jsw/reports/09.23_020_eda_review.md)은 기초 탐색 완료 범위이며 모든 과제 분석의 종료가 아니다. [analysis 002](reports/09.27_002_peak_conditions.md)는 사건·시작률·지속·조건·반복 가중, [003](reports/09.27_003_transition_context.md)은 생산 전환의 공통 월·시간 비교를 수행했다. 아래는 이 결과를 바탕으로 목적이 다른 후속 후보다. 30개를 모두 실행하라는 계획이 아니다.

**우선:** 지금 결론이나 과제 설명을 바꿀 가능성이 큼. **선택:** 사용할 결과·목적을 먼저 정함. **낮음:** 기존 분석과 겹치거나 가정·표본 제약이 큼. 통계적 모형을 쓰는 분석도 포함하지만, 목표는 예측 점수 개선이 아니다.

## 우선 실행할 조합

1. **1 기준 민감도**: 현재 피크 해석이 탐색 기준 182에만 매달리는지 점검.
2. **2 사건 심각도 + 3 집중도**: 002의 기간 차이를 큰 값·긴 지속·소수 기간 기여로 설명.
3. **7 기간 구성 분해**: 003의 조건 맞추기 관점을 기간 전체 차이에 적용. 공통 범위가 부족하면 부족 자체를 결과로 종료.
4. 위 결론에 필요할 때 **11 특정 기간 영향·26 비교 범위**를 검증으로 붙임.
5. 별도의 패턴 요약이 보고서에 필요하면 **19 PCA 또는 21 군집 중 하나**를 선택. FA는 수행 가능하지만 현재 열 구성에서는 우선순위가 낮음.

각 묶음은 이전 근거 → 질문 → 실행 전 비교·판단 기준 → 결과 → 해석 수정 → 다음/종료 순서로 진행한다. 분석 후보 정리는 새 결과를 얻었다는 뜻이 아니며, 이번 요청에서는 계산을 실행하지 않았다.

## 한 CSV 내부의 연결 방법

- **시간 표 ↔ 이전 시간 표**: 정확한 시각으로 연결. 직전 기록과 현재 결과를 분리.
- **사건 표 ↔ 날짜·시간·생산·날씨**: 시작·지속·심각도를 맥락과 연결. 사후 변수 표시.
- **일별 패턴 표 ↔ 일별 맥락 요약**: 날짜별 기록 합·기상 요약을 붙이되 실제 생산실적·에너지로 명명하지 않음.
- **프로필 표 ↔ 날짜·기간**: 반복 가중과 영향 분석. 실제 원관측 식별자로 간주하지 않음.

다른 제공 데이터와는 날짜가 겹친다는 이유만으로 결합하지 않는다. 같은 공장·설비·관측 범위라는 연결 근거가 필요하다.

## FA의 의미와 제공처 답변이 필요한 분석

앞선 보고서의 FA 불가능 설명은 **결함·고장 원인 분석**에 대한 것이다. FA가 **Factor Analysis(요인분석)**를 뜻한다면 한 CSV에서도 수행할 수 있다. 다만 요인분석도 잠재변수에 관한 통계 모형이며, 얻은 요인은 고장 원인이나 설비 부하의 식별 결과가 아니다. 날짜 숫자·달력 코드·서로 계산으로 연결된 열 전체를 그대로 넣는 것은 적절한 변수 설계가 아니다.

현재 입증할 수 없는 것은 설비별 고장 원인, 실제 에너지 원단위·효율, 공식 요금 기반 절감액, 생산일정 이동의 인과효과, 실제 운영 경보 성능이다. 제공처 설명으로 단위·집계·가용 시점이 명확해지고 연결 이력이 있어야 해당 질문을 열 수 있다.
