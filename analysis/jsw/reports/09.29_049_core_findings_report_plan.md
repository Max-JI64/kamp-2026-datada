# A049 — 핵심 Analysis 결과의 보고서 반영 계획

작성: 2026-09-29 | 상태: A049 실행 완료. 1~7절은 실행 전 계획, 8절은 저장 결과 대조 후 작성한 결과

## 1. 목적과 범위

[A048 이력 검토](09.29_048_report_scope_gap_audit.md)에서 이미 계산했지만 보고서 중심 논리에 충분히 반영하지 못한 두 결과를 확인했다. 이번 작업은 그 결과를 검증된 수치·대표 표·짧은 설명으로 정리하는 것이다.

1. 전체 평균이 낮아지거나 비슷해도 높은 전력값의 빈도가 늘어날 수 있는 이유.
2. 생산 전환과 고전력 시작의 단순 관계가 같은 조건을 맞추면 달라지는 이유.

기존 결과표를 재사용한다. 새 상관분석·분포 검정·군집·모델 학습을 시작하지 않는다. 새로운 제출 보고서 전체를 작성하거나 제출 준비로 전환하는 작업도 아니다. 여기서 설명하는 ‘이유’는 기록의 구성과 분포에 대한 설명이며 설비·작업의 물리적 원인 규명이 아니다.

## 3. 질문 A — 평균과 피크가 다른 방향으로 움직이는가?

### 출발 근거

- A033의 1~6월→7~8월 기록 평균은 전체에서 93.07→91.02로 낮아졌지만, 양수 생산 평일에서는 128.47→139.70으로 높아졌다. 이는 원분포 비교이며 같은 시각으로 표준화한 값과 다르다.
- A034는 평일/주말×생산량 0/양수의 네 집단으로 이 방향 차이를 분해했다. 특정 집단의 상승이 다른 집단의 하락과 합쳐지는 구조다.
- A035·037의 양수 생산 평일·동일 24시각 가중 비교에서 최대값 평균은 6월 146.41, 8월 147.52로 비슷하지만, 최대값 182 이상 비율은 13.57%→24.01%였다. A037이 높은 값과 낮은 값의 동시 변화로 평균이 상쇄되는 부분을 확인했다.

### 수행 순서

1. 위 수치를 해당 저장 표에서 대조한다. 목표가 저장 평균인지 네 칸 최대인지, 기간·조건·가중이 무엇인지 각 수치 옆에 적는다.
2. **전체와 조건별 방향 차이**, **한 조건 안에서도 평균과 높은 값 비율이 다른 변화**를 별개 주장으로 정리한다. 서로 다른 모집단의 수치를 한 쌍처럼 연결하지 않는다.
3. A034·037에서 각 주장을 직접 설명하는 기여 결과만 고른다. 모든 분위수·모든 집단을 본문에 옮기지 않는다.
4. A037의 날짜·주 제외 결과를 확인해 유지되는 결론과 민감한 결론을 구분한다. 기존 민감도 계산을 반복하지 않는다.
5. 본문 문단 하나와 대표 표 하나를 작성한다. 한 표 안에 두 비교를 넣으면 패널을 나누고 각 기간·조건·목표를 따로 표시한다.

### 해석과 모델링 연결

보고서에서는 “전체 평균만으로 모든 조건의 전력이 낮아졌다고 판단할 수 없고, 평균이 비슷해도 상위 전력 발생은 달라질 수 있다”를 핵심으로 쓴다. 따라서 전체 회귀 오차와 최대·고전력 구간의 평가를 함께 보는 이유가 된다.

이 결과만으로 새로운 최대 예측 모델이나 q75가 우수하다고 결정하지 않는다. 목표를 따로 평가할 이유와 특정 모델의 성능 증거는 구분한다. 182는 기존 탐색 기준이며 공식 운영 한계로 부르지 않는다.

## 4. 질문 B — 생산 전환은 보편적인 피크 위험조건인가?

### 출발 근거

A003에서 7~8월 고전력 시작 비율은 생산량 0→양수와 양수→양수의 전체 단순 비교에서 25.00%와 12.63%였다. 하지만 공통 월·시각 가중 비교에서는 14.68%와 15.48%로 큰 차이가 남지 않았다. 전환 기록이 피크 시작이 많은 시간대에 더 집중된 구성이 관련된다.

공통 범위로 제한한 단순 비교는 25.00%와 14.13%다. 따라서 전체 단순 비교에서 표준화 비교로 바로 넘어가며 모든 변화가 가중 때문이라고 설명하지 않는다. 비교 범위 제한과 구성 가중을 구분한다.

### 수행 순서

1. 전체 단순 비율 → 공통 범위의 단순 비율 → 공통 월·시각 가중 비율의 3행 비교표를 기존 결과에서 발췌한다.
2. 각 행의 분모·시작 사건 수·비교 범위를 표 또는 주석에 남긴다. 가중 비율에 원분모를 붙여 단순 비율처럼 읽히게 하지 않는다.
3. 같은 시각을 맞추는 이유를 짧게 설명한다. 생산 전환 기록이 8·13시에 얼마나 집중됐는지 기존 A003 수치로 뒷받침한다.
4. 1~6월에서는 차이가 남았다는 점, 양수→양수 기록 상당수가 공통 범위 밖이라는 점을 함께 기록한다. “생산량은 전력과 무관하다”로 확대하지 않는다.
5. 본문 문단 하나와 비교표 하나를 작성한다. 관측 관계를 인과효과나 현장 규칙으로 바꾸지 않는다.

### 해석과 모델링 연결

“생산 시작이면 항상 피크 위험이 크다”는 일반 규칙은 현재 결과로 뒷받침되지 않는다. 현재 시각 생산량의 사전 가용성도 미식별이므로, 생산조건은 우선 사후 오류 설명에 사용한다. 예측 입력 추가의 판단은 기존 M003 결과와 구분한다.

이 설명은 [M008 생산조건별 모델 오류 계획](../../../modeling/jsw/reports/09.29_008_production_error_comparison_plan.md)의 배경이 된다. 다만 M008이 끝날 때까지 A049를 보류할 필요는 없다.

## 8. 실행 결과 — 본문에 넣을 문단과 대표 표

이번 실행은 A003·A033~035·A037의 저장 CSV와 보고서를 대조해 문장과 표를 선별했다. A036은 A037 후속 질문을 고른 감사 기록으로 확인했다. 새 통계 계산, 원본 재집계, 모델 학습은 하지 않았다. 아래의 두 문단과 두 표를 보고서 본문용으로 채택한다. 표의 전력값은 CSV 기록값이며 원단위는 현 자료에서 미식별이다.

### 8.1 평균과 피크 빈도가 갈라지는 이유

**본문용 문단.** 1~6월에서 7~8월로 넘어갈 때 전체 기록의 `평균` 열 평균은 93.07에서 91.02로, 네 전력값의 시간별 최댓값 평균은 100.39에서 98.11로 낮아졌다. 그러나 같은 기간 생산량 양수 평일의 두 평균은 각각 128.47→139.70, 138.50→150.35로 높아졌다. 네 평일/주말×생산 유무 집단의 최댓값 평균 차이를 합치면 양수 생산 평일의 기여 +8.00이 다른 세 집단의 감소와 상쇄되어 전체 차이 −2.28이 된다. 한 집단 안에서도 중심과 상위 빈도는 따로 움직인다. 양수 생산 평일을 동일한 24시각 비중으로 맞춘 6월·8월의 최댓값 평균은 146.41→147.52로 가까웠지만, 최댓값 182 이상 시간 비율은 13.57%→24.01%였다. 188 이상 구간의 평균 기여가 +15.70 늘고 156~176 구간은 −15.41 줄어드는 등 값 구간의 변화가 서로 상쇄됐기 때문이다. 따라서 전체 평균이나 평균 예측오차만으로 높은 최대값의 빈도와 예측 실패를 판단하지 않고, 최대 목표와 고전력 구간도 따로 평가한다. 이 관측 차이만으로 특정 최대 예측 모델이나 q75의 우수성이 입증되지는 않는다.

### 8.2 생산 전환과 피크 시작의 관계가 달라지는 이유

**본문용 문단.** 7~8월에 직전 시간 네 값의 최댓값이 182 미만인 적격 시간에서 생산량 기록이 0→양수로 바뀐 경우의 고전력 시작은 13/52(25.00%), 양수→양수에서는 71/562(12.63%)였다. 먼저 두 전환이 함께 관측된 월×정확한 시각으로 범위를 제한하면 뒤쪽 비율이 39/276(14.13%)이 된다. 그 공통 범위에서 두 조합에 같은 층별 합산 노출 비중을 적용하면 두 시작률은 14.68%와 15.48%로 차이가 사실상 남지 않는다. 0→양수 기록의 19/52(36.5%)가 시작이 집중된 8·13시에 있고, 양수→양수는 55/562(9.8%)여서 단순 비율은 서로 다른 시각 구성의 영향도 담고 있다. 1~6월의 공통 월·시각 가중 비교에서는 10.27% 대 6.57%로 차이가 남으므로, 전환 자체를 기간에 걸쳐 일정한 피크 위험조건으로 일반화하지 않는다. 현재 생산량 기록의 사전 가용성도 현 자료에서 미식별이어서 이 관계는 사후 조건 설명에만 쓰고, 예측 입력 채택이나 전환의 인과효과로 해석하지 않는다.

**유지·수정:** 전체 평균 감소와 8월 높은 값 비율 증가는 각각 확인되지만, 서로 다른 기간·조건을 섞어 한 번의 평균 대 피크 비교로 제시하지 않는다. 8월의 ≥182 증가 방향은 날짜·주 하나를 제외해도 유지되는 반면 최댓값 평균의 주 제외 차이는 −1.15~+4.06으로 부호가 달라진다. A003의 7~8월 단순 관계는 공통 범위 제한과 구성 가중을 차례로 적용해야 해석이 바뀐다. 1~6월 차이가 남고 공통층이 작다는 제한도 유지한다.

**본문 제외:** A033의 모든 분위수와 A034의 네 집단 기여 전행, A037의 전체 구간·날짜 목록과 모든 임계값, A003의 전체 층별 표는 대표 두 주장에 추가 설명력이 작아 보조 근거로만 둔다. A036의 감사 목록, 다른 분포 검정·군집 결과는 이번 두 주장에 직접 필요하지 않아 본문에서 제외했다. 그림도 두 표보다 추가로 설명할 내용을 확인하지 못해 만들지 않았다.

**남은 한계·종료:** 값 구간의 구성 변화와 시간 구성은 관측 차이를 산술적으로 설명한다. 생산·기상·설비·계측 또는 기록 생성의 물리적 원인, 생산량의 예측 시점 가용성은 현 자료에서 미식별이다. A049의 두 질문은 저장 결과로 답했으므로 재집계·임계값 재탐색 없이 종료한다. 모델 자체의 생산량 크기·증감별 오류 비교는 별도 [M008 계획](../../../modeling/jsw/reports/09.29_008_production_error_comparison_plan.md)의 질문이며 A049의 종료 조건으로 삼지 않는다.
