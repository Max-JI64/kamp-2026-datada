# 036 — 전체 분석 이력과 현재 자료로 필요한 후속 분석

작성: 2026-09-27 | **문서·코드 검토와 필요성 판단만 수행. 신규 데이터 계산·모델 학습 없음.**

후속 실행 상태: 이 문서는 작성 당시의 계획과 판단을 보존한다. 이후 사용자 지시에 따라 [037 동일 조건 분포](09.27_037_distribution_followup.md), [038 해석용 FA·잔차](09.27_038_factor_followup.md), [039 생산·기상 공동 관계](09.27_039_joint_relationship.md)를 실행했다. 4번 날짜·주 민감도는 037·039에 붙였고, 3번의 PCA 잔차 제안은 사용자 요청에 맞춰 FA로 변경했다.

## 1. 이번 검토의 결론과 범위

**군집분석·PCA·요인분석·NMF는 이미 실행했다. 그러나 방법의 실행 완료와 결과의 후속 해석 완료는 같지 않다. 현재 CSV로 보완할 질문도 남아 있다.** 이전의 “남은 것은 제공처 자료가 있어야 가능하다”는 포괄적인 종료 판단은 수정한다. 자료가 필요한 물리적 원인 판정과, 현재 자료로 가능한 조건부 관계·분포·잔차 설명을 구분해야 한다.

검토 대상은 기존 보고서 **57개: EDA 21개, analysis 32개, modeling 4개**다. 세 단계 LOG, analysis의 30개 후보 계획과 README, modeling README, 원본 변수 진단표를 대조했다. 방법의 세부 실행 여부는 관련 코드·고정 설정·저장 산출물 경로로 확인했다. 전체 57개 문서의 회차별 판정은 7절에 남겼다. 이 숫자에는 자료 정의 점검·종합·감사 문서도 들어가며, 57개의 서로 독립적인 실험이라는 뜻이 아니다.

이번에 과거 분석을 전부 재실행하거나 모든 수치를 원본에서 독립 재계산하지 않았다. 이하 숫자는 해당 기존 보고서의 결과다. 사용자 최신 지시에 따라 **무엇이 더 필요한지 판단하는 단계에서 종료**한다. 017~019는 자료가 없어 예약만 된 번호이며 실행 회차에 포함하지 않는다.

## 4. 현재 자료로 필요한 후속 분석 — 우선순위와 종료 기준

아래는 **미실행 계획**이다. 1~5는 과제 분석, 6~7은 모델 오류·평가 분석이다. 이번에 새 분석 번호나 실행 완료 상태를 부여하지 않았다. 먼저 1~3을 수행할 가치가 크고, 나머지는 해당 결과를 보고 필요한 것만 선택한다.

### 후속 1 — 6월·7월·8월의 같은 조건에서 분포 차이 설명

- **이전 근거:** 035의 양수 생산 평일·동일 시각 최대값 평균은 146.41→152.78→147.52, 182 이상 비율은 13.57%→31.33%→24.01%다. 8월은 평균이 6월과 가까운데 높은 기록 비율은 더 크다.
- **이번 질문:** 기준 바로 아래 값이 위로 옮겨간 것인지, 낮은 값과 높은 값이 동시에 늘어 평균에서 상쇄된 것인지, 소수 날짜가 지배하는지 구분한다.
- **최소 방법:** 035와 동일한 집단·24시각 가중을 유지한 누적분포/분위수·기존 고정 값 구간의 비중과 평균 기여, 날짜별 기여를 비교한다. 182 전후만 잘라 보고 끝내지 않고 두 연속 목표 전체를 본다. 기존 176/188 민감도와 프로필 가중을 필요한 범위에서 연결한다.
- **판단 후 조치:** 임계값 인접 이동이면 기준 의존성을, 양끝 변화면 상쇄 구간을, 날짜 집중이면 해당 날짜의 현재 CSV 맥락을 설명한다. 이는 어떤 값들이 차이를 만들었는지에 대한 답이며 물리 원인은 별도다. 기준을 계속 바꾸는 탐색은 종료한다.

### 후속 2 — 생산량·기상·달력을 함께 고려한 조건부 관계

- **이전 근거:** EDA 006·007의 조건 내 상관은 작고, analysis 007의 생산 4구간 공통 범위는 7~8월 2층·62시간이다. 032의 기온 교집합도 동일 시각 비교가 충분한 층이 1개뿐이었다. 한편 033~035에서는 생산량 양수 여부만 맞춘 뒤 목표값 차이가 남았다.
- **이번 질문:** 생산량의 **연속적인 크기**와 기상값을 함께 고려하면 목표의 조건부 평균·상위값 및 기간 차이가 얼마나 달라지는가? 0/양수 구분만으로 답하지 못한 부분이다.
- **최소 방법:** 먼저 변수의 실제 관측 범위와 겹침을 점검한다. 겹치는 범위에서 달력만 → 생산량 추가 → 기상 추가 → 함께 고려한 설명 회귀를 비교한다. 양수 생산량의 로그/소수 스플라인 항, 생산 0 여부, 제한된 기온 곡선 등 단순하고 해석 가능한 형태를 사전에 고정한다. 비선형 분석에는 GAM 또는 스플라인 회귀가 후보이며 둘 다 실행할 필요는 없다. 목표에서 계산된 공장인원과 동시 전력 구성값은 설명 입력에서 제외한다.
- **판단 후 조치:** 같은 행에서 조건부 관계와 설명되지 않은 기간 차이를 비교하고, 날짜·주 및 반복 프로필에 따른 불안정성을 확인한다. 기간과 월을 중복 투입해 계수를 해석하지 않는다. 관측이 없는 생산·기상 조합까지 외삽해야 한다면 그 범위는 답하지 않는다. 모형을 단순화하거나 일부 정보를 묶는 가정은 새로운 정보가 아니므로 한계를 보고한다.
- **가능한 결론:** “현재 열을 함께 고려한 관측 연관”까지다. 사후 설명을 위한 통계 모형 사용이며 미래 예측 모델 선택과 분리한다. 계수·설명력·SHAP 수치를 생산/기상의 인과 기여율로 바꾸지 않는다.

### 후속 3 — PCA가 놓친 차이를 날짜·시간·현재 변수로 연결

- **이전 근거:** 008에서 PC1은 주로 하루 수준이며, 6성분 재구성 오차가 후기 날짜에서 커졌다. 원척도 PC2도 훈련 분산 13.25%를 설명하나 본문의 형태 해석은 짧다.
- **이번 질문:** 기존 수준·형태 축으로 설명되지 않는 값은 어느 날짜·시각에 있으며, 높은 전력·0 기록·생산/날씨·기존 군집과 어떻게 겹치는가?
- **최소 방법:** 기존 6성분 적재·점수와 학습 평균을 재사용해 시각별 재구성 잔차를 추적하고, 오차 상위 날짜와 대표적인 낮은 오차 날짜를 현재 CSV 맥락으로 설명한다. PC2 적재의 주요 시간대를 함께 확인한다. PCA의 재구성 잔차와 예측 모델의 예측 잔차를 구분한다.
- **판단 후 조치:** 특정 시간/날짜의 형태 차이인지 넓은 차이인지 보고한다. 1~6월 적합 오차가 작은 것은 적합자료라는 이점이 있으므로, 후기 차이를 새 상태 발견이라고 주장하려면 1~6월 내부의 시간 분할·완전 동일 프로필 겹침을 고려한 참조 오차 비교가 추가로 필요하다. 사후 특이 사례 설명만 한다면 고장 임계값을 만들지 않고 종료한다.

### 후속 4 — 최신 목표값 차이의 날짜·주 의존성 확인

- **이전 근거:** 005의 단일 월/주/프로필 제외와 블록 재표집은 주로 전체 기간의 시작·고전력 비율을 다뤘다. 035는 양수 생산 평일의 6·7·8월 비교이며 날짜 수도 22·20·17일로 달라 검증 범위가 같지 않다.
- **최소 방법:** 후속 1의 주요 차이만 대상으로 날짜/주 묶음을 하나씩 제외한 민감도와 반복 가중을 먼저 확인한다. 불확실성 범위를 제시할 필요가 있을 때만 날짜·주 블록 재표집을 추가한다. 기준·시각 가중 재산정 원칙과 공통층 소실 처리도 먼저 정한다.
- **판단 후 조치:** 한두 날짜에 결론이 의존하면 해당 관측으로 한정하고, 방향이 유지되면 그 민감도 범위만 확인한 것으로 종료한다. 반복 생성 미확인 자료의 공식 모집단 신뢰구간으로 제시하지 않는다. **전체 파일의 정확한 기술 평균을 보고하는 데 p값은 필수가 아니다.**

### 후속 5 — 전력으로 만든 군집 밖에서 조건 유형을 확인할 필요가 있는가

- **이전 근거:** 024의 군집→고전력 비교는 같은 전력값의 재표현이고, 027은 전력 군집이 생산 상태와 일대일 대응하지 않음을 확인했다.
- **우선 판단:** 후속 2의 조건부 관계가 이해 가능한 설명을 주면 새 군집은 불필요하다. 조건 조합이 복잡해 사례를 정리할 목적이 남을 때만 진행한다.
- **조건부 방법:** 전력 목표·전력 기반 군집·공장인원을 제외하고 생산 기록·기상·달력으로 관측 조건을 요약한 뒤, 별도로 목표 전력 분포를 비교한다. 변수의 척도·0/양수 구조·날짜 단위를 먼저 고정한다. 유형이 단순 월/계절 구분인지와 기간·반복 가중 민감도를 확인한다.
- **판단 후 조치:** 전력 목표를 군집 입력에 넣지 않아 순환성은 줄지만, 사후 자료의 군집은 인과 대조군이 아니다. 유형이 불안정하거나 기존 달력·생산 분할 이상의 설명을 주지 못하면 종료한다. 새 군집법들을 모두 시도하는 계획은 아니다.

### 후속 6 — 높은 전력 지속에서 모델이 낮게 예측하는 이유

- **위치:** 실행한다면 `modeling/jsw`에 둔다.
- **이전 근거:** modeling 001에서 7~8월 높은 전력 지속 119시간의 최대값 MAE는 직전값 6.95 대 모델 13.38, 111시간이 과소예측이었다. modeling 002는 손실함수 교환관계를, 003은 직전 생산·날씨의 추가 가치를 보았지만, 실패한 입력 상태가 학습에 얼마나 있었는지는 별도 질문이다.
- **최소 방법:** 저장 예측의 실패 시각과 성공 시각을 학습 입력의 가까운 사례·목표 분포·달력 전환과 대조한다. 목표가 학습 최댓값을 넘었는지만이 아니라 과거 전력과 달력의 **조합**이 지원되는지 본다. 학습 범위, 평균 방향으로의 예측 편향, 상태 전환 중 무엇과 오류가 동반되는지 구분한다.
- **판단 후 조치:** 모델의 실패 메커니즘에 관한 후보를 좁힌다. 실제 전력 증가의 물리적 원인을 찾은 것으로 쓰지 않고, 이미 본 7~8월에서 설정을 조정한 뒤 독립 시험 성능이라고 보고하지 않는다.

### 후속 7 — 모델 잔차의 시간 구조와 분위수의 실현 비율

- **위치·우선순위:** 모델링 보완, 현재 목표 원인 질문보다 후순위.
- **이전 근거:** 모델링은 시간대·월·상태별 오차와 0.75 분위수의 놓침/과대예측을 비교했으나, 예측 잔차의 연속성과 명목 0.75에 대한 실제 이하 비율을 별도 교정 진단으로 보고하지 않았다.
- **최소 방법:** 저장 예측만 사용해 잔차의 정확한 시차·조건별 편향, 0.75 예측값 이하의 실제값 비중과 분위수 손실을 개발 월별로 확인한다. 5월 높은 사례의 작은 분모를 유지한다.
- **판단 후 조치:** 남은 시간 구조와 분위수 해석의 범위를 정리한다. 단일 분위수는 예측구간이 아니며, 비용을 비대칭으로 둔 후보로만 사용할 경우 완전한 구간 추정까지 자동 확대하지 않는다.

## 5. 아직 안 한 방법과 필요성

보고서·관련 스크립트에서 다음 방법의 실행 근거를 찾지 못했다. “미실행”은 “필수 누락”과 다르다.

| 방법 | 현재 자료로 계산 가능 여부 | 이번 판단 |
|---|---|---|
| GAM·스플라인 기반 설명 회귀 | 가능. 공통 범위·모형 가정 확인 필요 | 후속 2의 구체적인 후보. 우선 검토 가치 있음 |
| 설명 목적의 조건부 분위수 회귀 | 가능. 작은 조건의 상위 분위수는 불안정 | 평균 관계와 상위값 관계가 실제로 다른지 필요할 때 선택. 기존 **예측용 HGB 0.75**와 구분 |
| 전력을 제외한 조건 군집 | 가능 | 후속 5의 조건부 선택. 기존 전력 군집과 다른 질문 |

| t-SNE·UMAP | 가능 | 시각화용. 현재의 원인 후보·후속 누락을 해결하지 않으며 2차원 분리만으로 군집을 입증하지 못함 |

| 다중 시점 변화 탐지·HMM | 계산은 가능 | 006 단일 후보·STL의 후속 목적이 불명확하고 상태 라벨도 없음. 현재 우선순위 낮음 |
| PCA 부분공간/FA 적재의 기간·반복 민감도, 요인 수 진단 | 가능 | 축을 핵심 설명으로 채택할 때 필요. 군집 안정성 결과로 대신했다고 쓰지 않음. KMO/Bartlett 통과만으로 물리 요인 존재를 주장하지 않음 |
| SHAP·순열 중요도·ALE | 모델이 있으면 가능 | 원인 분석의 대체물이 아님. 설명 모형/예측 모형의 사용 목적과 상관된 입력 처리부터 정한 뒤 필요한 경우만 |

## 6. 종료 판단을 어떻게 바꾸는가

1. **유지:** 같은 상관·임계값·군집 수를 끝없이 바꾸는 작업은 하지 않는다. 실제 고장/설비 원인, 일정 변경 효과, 비용 절감은 현재 자료만으로 확정하지 않는다.
2. **수정:** 기법을 여러 개 실행했고 직접 원인을 확정하지 못했다는 이유로, 잔차·조건부 관계·최근 집단의 분포 설명까지 모두 종료하지 않는다.
3. **현재 우선순위:** 후속 1의 정확한 비교 대상 분포 → 후속 2의 관측 범위와 공동 관계 → 후속 3의 PCA 미설명 패턴. 후속 4는 이들 주요 결과의 필요한 민감도로 붙이고, 후속 5~7은 목적별 선택이다.
4. **이번 종료:** 검토·계획 문서만 작성한다. 새 CSV 통계, 예측값, 적합 모형, 그림은 만들지 않았다. 실제 실행은 이후 사용자의 진행 지시에 따른다.

문서 대조 중 030의 “031 검증에서 사건 시작 시각별 시간 합도 원본과 대조”라는 문장은 현 [031 검증 코드](../scripts/09.27_031_verify_target_explanation.py)의 범위와 맞지 않았다. 해당 코드는 달력 셀 기여·분모·연속 목표·집단/월별 표준화를 검사한다. 030의 재현 설명을 이에 맞춰 정정하며, 보류된 사건 시작 시각 후속을 실행한 것으로 세지 않는다.

## 8. 이번 검증 범위

- 보고서·로그·계획·관련 구현을 대조한 문서 감사다. 과거 Python 종료 코드는 과거 실행 기록이며 이번 재실행 결과가 아니다.
- 새 보고서의 기존 근거 링크와 회차 목록, 수정 문서의 경로·문장 일관성을 점검한다. 이 점검은 데이터 재계산이나 통계적 타당성의 자동 인증이 아니다.
- 원본 CSV, 기존 결과표·설정·코드·모델은 변경하지 않는다. 현재 입구는 이 문서이며 이전 종료 판단의 이력은 보존한다.
