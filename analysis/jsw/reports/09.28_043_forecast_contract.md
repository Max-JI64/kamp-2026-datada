## 이전 근거 → 설계 질문

[041 계획](09.28_041_guidebook_analysis_scope.md)의 4번은 과제공개의 `향후 지정된 시간구간`이 몇 분인지 정하지 않은 상태에서 예측 대상·정보 시점을 먼저 고정하도록 했다. [E021](../../../EDA/jsw/reports/09.26_021_analysis_readiness.md)은 정확한 과거 연결의 행 수를, [modeling 001](../../../modeling/jsw/reports/09.26_001_power_models.md)은 이미 **다음 한 시간 기록의 평균과 네 칸 최대**를 각각 예측한 오프라인 실험을 제공한다. 새로운 15분 목표로 바꾸면 기존 성능과 직접 비교할 수 없으므로, 현재 보고서·구현의 공통 계약을 명시한다.

## 현재 채택할 오프라인 예측 계약

| 항목 | 정의와 경계 |
|---|---|
| 예측 시점 | 기록 `t−1`의 네 전력 칸이 모두 완료·확인됐다고 놓고 다음 **기록 순서** `t`를 예측한다. 실제 시계·수집 지연은 미확정. |
| 수평선 | 정확히 다음 한 시간 기록 **1개**. 매 기록이 완료되면 한 단계씩 다시 예측한다. 장기 다중 단계 예측은 이 성능의 대상이 아니다. |
| 주 목표 | 다음 기록의 CSV `평균` 열. 네 전력 칸 평균을 반올림한 저장값이며 단위는 미확정. |
| 별도 목표 | 다음 기록의 `15분·30분·45분·60분` 네 값 중 최대. 15분 각각의 값이나 공식 최대수요전력이 아니다. |
| 사전 입력 후보 | 목표 기록의 달력 시각·요일·월과 **완료된 과거 전력 기록**만 사용. 정확한 1·2·3·24·168시간 전 기록과 직전 24시간 통계는 해당 연결이 있을 때만 사용한다. |
| 현재 제외 | 목표 시간의 전력·생산량·실황 날씨·`공장인원`·비용. 미래 생산 계획과 기상 예보의 생성·가용 시점이 검증되지 않아 미리 아는 값으로 넣지 않는다. |
| 기록 공백 | 시각 0~23 밖 48행은 복원하지 않고 정확한 과거 연결이 성립하는 대상만 사용한다. 0 전력은 유지한다. |

[E021](../../../EDA/jsw/reports/09.26_021_analysis_readiness.md)에서 정상 5,784시간 중 직전 1시간 연결 5,781개, 직전 168시간 **전체 연속** 연결 5,424개다. 이 둘은 다른 조건이다. [modeling 001](../../../modeling/jsw/reports/09.26_001_power_models.md)의 사용 가능 공통 시각 **5,520개**는 해당 모델의 정확 시차·직전 24시간 조건을 적용한 수이며, 여기서 새 목표 표본 수로 대체하지 않는다. 기존 7~8월 평가 1,344시간은 이미 확인된 구간이므로 새로운 독립 시험으로 부르지 않는다.

## 판단과 다음 단계

과제 문구가 지정 구간 길이를 확정하지 않았으므로 **다음 시간 기록 1개**를 현재 구현·보고서 비교의 계약으로 채택한다. 다음 15분 값이나 여러 시간을 동시에 예측하려면 목표 정의, 입력 시점, 공통 평가 시각을 다시 명시하고 별도 모델링 실험으로 다룬다. 물리적 시간 앵커·수집 지연이 확인되지 않은 현재 성능은 기록 순서 기반 오프라인 성능이며 실시간 운영 성능이 아니다. 새로운 학습이나 기존 점수 재해석 없이 설계 질문을 종료한다.
